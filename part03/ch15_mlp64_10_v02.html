제15장 · 64→10 정수 MLP 분류기

64특징에 10개 가중치 행과 Bias를 곱해 손글씨 클래스 점수를 만드는 단일 계층을 실습합니다.

단일 Dense단계형 실습PC 기준값 비교

00과제 개요

64특징에 10개 가중치 행과 Bias를 곱해 손글씨 클래스 점수를 만드는 단일 계층을 실습합니다.

선수학습: 13장 입력, 14장 10분류 그룹

산출물: W[10][64]·B[10]의 정수 Score 기준모델

01구조와 데이터 흐름

64×10=640 MAC을 수행합니다. 은닉층이 없는 단일 Dense 구조로, 16장의 2계층 MLP와 구분합니다.

02핵심 설계 규격

  • 입력 x[64], 가중치 w[10][64], Bias[10]을 사용하고 10개 signed 원점수를 생성한다.
  • Softmax를 하드웨어에 구현하지 않아도 원점수 Argmax로 예측 클래스를 선택할 수 있다.
  • 가중치에 임의 예제값을 쓴 경우 그 출력은 회로 산술 검증용이며 학습 정확도가 아니다.
  • 실제 MNIST 정확도를 논하려면 13장의 전처리와 맞춘 학습된 가중치를 사용해야 한다.

03실습 절차

  1. 첫 입력을 64개로 만들고 가중치 10행을 각 64개로 정의한다.
  2. 10개 Bias를 더한 signed 점수를 Python 기준모델로 계산한다.
  3. 4PE 그룹 [4,4,2]에 출력 점수를 매핑해 본다.
  4. 전체 점수가 동점일 때 가장 작은 클래스 번호가 선택되는지 확인한다.

04구현 및 확인 코드

독립 기준모델 또는 실습 코드이며, 실제 FPGA 배치·동작 검증과는 별개입니다.

15장 Python 정수 기준모델 · python
from part03.host_tools.p3_integer_reference import (
    linear_64x10, argmax_lowest,
)
x = [1]*64
w = [[int(j == i) for j in range(64)] for i in range(10)]
scores = linear_64x10(x, w, [0]*10)
print("scores=", len(scores), "class=", argmax_lowest(scores))

예상 출력

scores= 10 class= 0

05검증 및 실습 점검

  • W 행 수와 각 행 길이가 정확히 10×64인지 확인한다.
  • 음수 Bias·동점·길이 불일치 오류가 검출되어야 한다.
  • RTL 구현 후 10개 점수를 개별 정수 비교한다.

Python 호스트 정답, RTL 시뮬레이션, Vivado 합성·타이밍, 실물 관찰은 별도 검증으로 기록합니다.

06오류를 피하는 기준

  • 단순 원-핫 가중치 예제를 실제 학습 모델이라고 주장하지 않는다.
  • 64→10은 은닉층이 있는 MLP와 구조가 다르다.
  • 10클래스 RTL 기능은 실제 구현·시뮬레이션 전까지 미검증이다.

07누적 RTL 실습 · 입력부터 Basys3 출력까지
