BASYS3 · MicroBlaze V · 제3부 26/31

제26장 · 3×3 소형 CNN 연산 확장

8×8 단일채널 영상에서 3×3 합성곱과 ReLU를 적용해 작은 특징맵을 만드는 데이터 경로를 설계합니다.

CNN 입력기능 분리검증 절차

00과제 개요

8×8 단일채널 영상에서 3×3 합성곱과 ReLU를 적용해 작은 특징맵을 만드는 데이터 경로를 설계합니다.

선수학습: 04장 BRAM·07장 Dot·17장 분할 공급

산출물: 6×6 출력맵·3×3 윈도우·9개 MAC/픽셀 기준값

01시스템 구조

Stride 1, Padding 0인 8×8 입력·3×3 커널의 출력 크기는 6×6입니다. 첫 단계에서는 1입력채널·1출력채널로 한정합니다.

02핵심 설계 계약

  • 딥러닝 합성곱 라이브러리의 기본 Conv2d는 커널 뒤집기 없는 Cross-Correlation 계산이다.
  • 한 출력 픽셀마다 9개 곱-누산, 출력 36픽셀이므로 필터 1개당 324MAC이다.
  • 9개 윈도우 원소를 제대로 공급하기 위한 Line Buffer/Window Generator가 추가로 필요하다.
  • 8×8·1채널 예제는 28×28 CNN 전체 구현이나 YOLO 영상 객체검출을 의미하지 않는다.

03따라 하기 실습

  1. 8×8 이미지 배열과 3×3 커널을 준비한다.
  2. 6×6 위치를 순회해 각 3×3 영역의 9항 내적을 구한다.
  3. Python 출력맵과 RTL 컨볼루션 코어의 Score/Valid 타이밍을 비교한다.
  4. BRAM 포트와 라인 버퍼의 윈도우 공급 주기를 검토한다.
  5. 채널 수를 늘리기 전에 현재 1채널 회로의 Timing/Resource와 정답을 확인한다.

04코드·설정 예제

다음은 단일 채널 8×8 입력에 대한 실행 가능한 순수 Python 기준모델이다. 이 코드는 실습용 예제이며 실제 Vivado·Vitis 빌드 성공과 구분합니다.

CNN 8×8·3×3 정수 기준값 · python
img = [[r*8+c for c in range(8)] for r in range(8)]
kernel = [[1,0,-1],[1,0,-1],[1,0,-1]]
out = [[sum(img[r+i][c+j]*kernel[i][j]
            for i in range(3) for j in range(3))
        for c in range(6)] for r in range(6)]
assert len(out) == 6 and len(out[0]) == 6
print("shape=",len(out),"x",len(out[0]),"first=",out[0][0])

예상 출력·확인 조건

shape= 6 x 6 first= -6

05검증 항목

  • 출력 6×6, 첫 출력값 -6을 확인한다.
  • 윈도우의 상하좌우 이동 시 입력 주소가 중복/누락되지 않는다.
  • 실제 RTL에서는 Pixel Valid/Window Valid와 BRAM 읽기 지연을 별도 검증한다.

호스트 계산, RTL Simulation, Synthesis·Timing, Basys3 실물 게이트의 증거를 서로 구분해 기록합니다.

06오류·확장 경계

  • FPGA에 카메라 입력이 없으면 Python 생성·UART 입력을 시험 데이터로 쓴다.
  • 8×8 간단 CNN을 28×28 고급 객체검출 모델로 해석하지 않는다.
  • Line Buffer나 Multi-Channel은 메모리 자원 검증을 거친 후 확장한다.
