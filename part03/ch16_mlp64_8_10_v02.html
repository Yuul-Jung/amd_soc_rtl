제16장 · 64→8→10 다층 정수 MLP

64개 특징에서 8개 은닉 뉴런을 거쳐 10개 점수를 생성하는 2계층 MLP를 설계합니다.

2계층 모델단계형 실습PC 기준값 비교

00과제 개요

64개 특징에서 8개 은닉 뉴런을 거쳐 10개 점수를 생성하는 2계층 MLP를 설계합니다.

선수학습: 15장 64→10, 05장 Fixed Quantizer

산출물: 512+80=592 MAC과 ReLU·INT8 재양자화 기준모델

01구조와 데이터 흐름

첫 Dense8은 512개, 두 번째 Dense10은 80개 MAC을 수행합니다. 층 사이 재양자화가 하드웨어 정수 모델의 핵심입니다.

02핵심 설계 규격

  • 가중치 W1[8][64] 512개, W2[10][8] 80개, Bias 8+10개.
  • ReLU는 1계층 출력에만 적용하며 최종 분류 점수에는 불필요한 ReLU를 적용하지 않는다.
  • 반올림·포화·Scale/Shift를 호스트 기준모델과 RTL에서 정확히 일치시킨다.
  • 4PE 처리그룹은 은닉층 2회와 최종 출력층 3회로 분리한다.

03실습 절차

  1. 64개 입력을 Dense8으로 처리하고 ReLU를 적용한다.
  2. 중간값을 INT8 범위로 양자화해 두 번째 Dense10으로 전달한다.
  3. 동점·음수 점수·중간값 포화 시험을 구성한다.
  4. 8×8 축소 모델과 28×28 원본 모델의 정확도 자료를 섞지 않는다.

04구현 및 확인 코드

독립 기준모델 또는 실습 코드이며, 실제 FPGA 배치·동작 검증과는 별개입니다.

16장 Python 2계층 기준모델 · python
from part03.host_tools.p3_integer_reference import (
    mlp_64_8_10, argmax_lowest,
)
x = [1]*64
w1 = [[int(j == i) for j in range(64)] for i in range(8)]
w2 = [[int(j == i%8) for j in range(8)] for i in range(10)]
scores = mlp_64_8_10(x,w1,[0]*8,w2,[0]*10,0)
assert len(scores) == 10
print("class=", argmax_lowest(scores))

예상 출력

class= 0

05검증 및 실습 점검

  • 은닉층 8개·출력층 10개 점수의 크기를 확인한다.
  • ReLU 음수 제거·Shift 절반값·포화 경계가 일치하는지 검사한다.
  • 1계층과 2계층 사이에 Ready/Valid·버퍼 소유권을 정의한다.

Python 호스트 정답, RTL 시뮬레이션, Vivado 합성·타이밍, 실물 관찰은 별도 검증으로 기록합니다.

06오류를 피하는 기준

  • 1계층과 2계층 가중치를 하나의 4PE 배열로 동시에 처리한다고 가정하지 않는다.
  • 중간값 스케일을 무시하면 학습된 모델과 정수모델 정합성이 깨진다.
  • 가중치가 모두 0/1인 코드 예제는 산술 검증용이다.
