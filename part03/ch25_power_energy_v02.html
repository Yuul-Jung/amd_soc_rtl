BASYS3 · MicroBlaze V · 제3부 25/31

제25장 · 전력·추론 에너지 평가

활성/유휴 전력·클록·토글률·추론 지연을 구분하여 전력과 추론당 에너지를 분석합니다.

Power 분석기능 분리검증 절차

00과제 개요

활성/유휴 전력·클록·토글률·추론 지연을 구분하여 전력과 추론당 에너지를 분석합니다.

선수학습: 24장 구현 자원, 23장 추론 시간

산출물: Vivado Power Report 및 활성/유휴 전력·추론당 에너지 표

01시스템 구조

Estimated Dynamic Power와 실제 보드 측정값은 별개입니다. 전력 감소량과 소모 에너지도 구분합니다.

02핵심 설계 계약

  • VCCINT/VCCAUX/VCCO를 구분하고 I/O 부하·토글률·클록을 실제 조건으로 입력한다.
  • SAIF/VCD와 같은 실제 활동 정보가 없으면 기본 토글 가정에 의존할 수 있어 추정 불확실성을 밝힌다.
  • 추론당 추가 에너지는 (활성 전력−유휴 전력)×추론 시간으로 계산할 수 있다. 시스템 전체 에너지는 유휴 전력 포함 조건을 별도로 정한다.
  • 열·전원 무결성은 제4부 전체 최적화 과정과 연결하되 제3부에서는 NPU 연산 전력으로 한정한다.

03따라 하기 실습

  1. 24장 구현 대상의 Toggle/Clock/Voltage 조건을 확인한다.
  2. 유휴·추론 동작을 구분해 활동도 파일 또는 시뮬레이션 파형을 확보한다.
  3. Vivado Report Power에서 Static/Dynamic·I/O 등 항목을 읽는다.
  4. 23장에서 확보한 실측 추론 시간과 결합해 추론당 추가 에너지를 계산한다.
  5. 동일 모델에서 PE 수·클록·정밀도별 결과를 같은 조건으로 비교한다.

04코드·설정 예제

다음 값은 계산 방법을 보여주는 가상의 수치이다. 이 코드는 실습용 예제이며 실제 Vivado·Vitis 빌드 성공과 구분합니다.

추론당 에너지 계산 · python
idle_w = 0.40     # 예시값, 실제 보고서/계측으로 교체
active_w = 0.62   # 예시값
latency_ms = 2.0  # 예시값
delta_j = (active_w-idle_w)*latency_ms/1000
print("example additional mJ=", round(delta_j*1000, 3))

예상 출력·확인 조건

example additional mJ= 0.44

05검증 항목

  • Static/Dynamic 전력 추정치를 혼합하지 않는다.
  • 입력 데이터·클록·온도·측정 지점을 보고서에 기재한다.
  • J(에너지)와 W(전력)의 단위를 혼동하지 않는다.

호스트 계산, RTL Simulation, Synthesis·Timing, Basys3 실물 게이트의 증거를 서로 구분해 기록합니다.

06오류·확장 경계

  • 0.44mJ는 계산 예제이며 실제 Basys3 소비전력이 아니다.
  • Vivado Report Power의 추정값을 실측 파워미터 결과로 보고하지 않는다.
  • 전원 레일·부하·외부 모터 전원은 NPU 코어 전력과 분리한다.
