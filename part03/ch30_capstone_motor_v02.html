제30장 · NPU 기반 지능형 모터 제어 시스템

NPU가 목표 동작 모드를 제안하고 독립된 RTL 모터 Controller와 안전 인터록이 실제 PWM·방향을 제어하도록 설계합니다.

종합 3 · 구동 제어종합 제작과제독립 검증

00과제 개요

NPU가 목표 동작 모드를 제안하고 독립된 RTL 모터 Controller와 안전 인터록이 실제 PWM·방향을 제어하도록 설계합니다.

선수학습: 29장 상태감시, 제2부 모터 드라이버·PWM

산출물: NPU 추천값→승인/인터록→RTL 모터 Controller→안전한 모터 구동

01시스템 구조

모터 제어는 시간 결정성이 중요하므로 NPU는 상위 정책/추천값에만 관여하고 과전류·비상정지·온도 등 안전 보호는 독립해야 합니다.

02핵심 설계 규칙

  • AI/NPU 출력이 직접 PWM 핀이나 모터 드라이버의 Enable을 구동하지 않는다.
  • Hard Stop, Limit Switch, Fault, Watchdog, Reset은 AI 점수와 무관하게 모터 OFF를 우선한다.
  • 정회전↔역회전은 Dead Time/Stop 구간과 드라이버 데이터시트를 고려한다.
  • 외부 모터는 별도 전원과 역기전력/전류 보호를 사용한다. FPGA 핀에서 직접 모터를 구동하지 않는다.
  • NPU 추론이 지연되거나 UART가 끊겨도 안전한 상태가 유지돼야 한다.

03따라 하기 실습

  1. 기존 독립 RTL PWM/모터 Controller 인터페이스를 확인한다.
  2. NPU 결과를 Speed/Direction 후보로 변환하는 정책 Controller를 별도 모듈로 설계한다.
  3. Safety Interlock이 Enable=0을 최우선으로 결정하도록 회로를 구성한다.
  4. E-Stop·Watchdog Timeout·과전류 고장 입력을 NPU 이상 여부와 별개로 주입해 시험한다.
  5. 모터가 연결되지 않은 가상 부하/LED부터 검증하고, 실제 구동은 외부 전원·보호회로를 확인한 뒤 시행한다.

04코드 및 처리 기준

다음 코드는 AI 추천과 무관하게 안전 입력이 모터 Enable을 차단하도록 하는 교육용 정책 모델이다.

30장 정지 우선순위 정책 · python
def motor_policy(npu_speed, estop, fault, fresh):
    # NPU 출력은 안전 조건을 통과했을 때만 사용한다.
    if estop or fault or not fresh:
        return 0
    return max(0, min(100, int(npu_speed)))

assert motor_policy(80, True, False, True) == 0
assert motor_policy(80, False, True, True) == 0
assert motor_policy(80, False, False, False) == 0
print(motor_policy(80, False, False, True))

예상 출력·확인 조건

80

05동작 및 안전 검증

  • 비상정지, 고장, 데이터 수신 중단 중 하나라도 참이면 Enable=0.
  • 정·역전환, PWM 0/100%, Reset·전원 복귀 시 안전상태 검증.
  • Motor Driver가 실제 전압/전류·레벨에 맞는지 실물에서 확인.
  • 실물 안전 보호를 NPU 검증 PASS로 대체하지 않는다.

시뮬레이션·합성·실물 확인은 실제 실행 증거가 있는 경우에만 통과로 판정합니다.

06제약사항과 확장

  • 이 코드는 인증된 기능안전 로직이 아니며 모터 제어기 전체 RTL도 아니다.
  • NPU 오분류나 모델 로딩 실패가 모터의 위험 동작으로 이어지면 안 된다.
  • 상용 안전장치의 보호 정지 책임을 임의 교육용 AI 회로에 맡기지 않는다.

07종합과제 · 공통 SoC 이어받기와 보드 확인

① 그대로 유지할 시스템

29장 상태 구분 및 기존 PWM/모터 Controller, 27장 CPU+NPU SoC

② 이번 종합과제의 추가 기능

NPU가 제안한 명령과 승인/인터록 Controller, 실제 PWM·방향 출력의 우선순위를 분리한다.

③ 실습·실제 보드 확인

모터를 연결하지 않고 먼저 FPGA PWM/방향·강제 정지 출력 확인 → 전원/드라이버/비상정지 검토 후 실물 구동; 안전은 AI 분류에 의존하지 않음

④ 완성 후 보존할 산출물

검증된 공통 SoC는 그대로 남기고 모터 응용은 독립 분기 유지

28~31장 종합과제 분기·센서·모터·암호 장치의 보드 확인 기준. 공통 NPU SoC에 임의로 위험 제어를 결합하지 않는다.
