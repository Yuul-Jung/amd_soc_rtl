제28장 · 손글씨 숫자 인식 NPU 시스템

PC의 손글씨 입력을 Python 전처리·정수 10분류 NPU·MicroBlaze V 결과 표시로 잇는 종합 실습입니다.

종합 1 · MNIST종합 제작과제독립 검증

00과제 개요

PC의 손글씨 입력을 Python 전처리·정수 10분류 NPU·MicroBlaze V 결과 표시로 잇는 종합 실습입니다.

선수학습: 13~19장 MNIST/MLP, 20~27장 NPU SoC

산출물: 숫자 0~9 입력→10개 signed 점수→Class→UART/FND 종합 기록

01시스템 구조

교육용 8×8 또는 타일링된 28×28 방식 중 실제 구현한 모드만 사용합니다. 10분류는 신규 10출력 스케줄이 검증된 상태여야 합니다.

02핵심 설계 규칙

  • 실습 모드를 8×8·64 입력 또는 28×28·784 타일링으로 명시한다. 두 모델의 가중치와 정확도는 별개다.
  • 학습 모델·정수 양자화·하드웨어 예측 클래스는 같은 모델 ID, 이미지 ID, 스케일 설정으로 연결한다.
  • 본 장은 12장 4클래스 단순 데모와 별개로 숫자 0~9를 다룬다.
  • GUI를 새로 개발할 필요 없이 PC 이미지 파일·기존 터미널·Python 기준모델을 활용한다.
  • MicroBlaze V는 버스 제어/결과 전송, RTL은 10개 Score의 병렬·분할 MAC을 수행한다.

03따라 하기 실습

  1. 13장 입력 전처리 규칙과 학습된 64→8→10 또는 784 기반 모델 가중치를 고정한다.
  2. 16~17장의 동일한 INT8/INT16 정수 모델로 PC Golden 10점수를 생성한다.
  3. 20~22장의 NPU 레지스터에 입력/가중치를 적재하고 실행/완료를 확인한다.
  4. 10개 점수 및 Class를 UART 터미널과 FND/LED로 관찰한다.
  5. 시험 이미지 번호별 CPU/GOLDEN/FPGA 결과를 CSV로 기록하고 불일치 원인을 분류한다.

04코드 및 처리 기준

아래 코드는 임의 가중치를 사용한 정수 연산 계약 점검이다. 실제 MNIST 인식 정확도는 학습 모델에서 별도로 확인한다.

28장 10클래스 Score 확인 · python
from part03.host_tools.p3_integer_reference import (
    linear_64x10, argmax_lowest,
)
x = [1]*64
w = [[int(i == j) for j in range(64)] for i in range(10)]
scores = linear_64x10(x,w,[0]*10)
print("score_count=", len(scores), "class=", argmax_lowest(scores))

예상 출력·확인 조건

05동작 및 안전 검증

  • 동일 입력·동일 가중치의 전체 10개 점수와 최종 클래스를 비교한다.
  • 0~9 각 클래스 및 오류 입력·미적재 가중치를 시험한다.
  • 실제 FPGA NPU 측정 결과와 PC 기준값을 서로 다른 근거로 기록한다.
  • 호스트 학습 정확도와 보드 실제 추론 정확도를 별도 측정한다.

시뮬레이션·합성·실물 확인은 실제 실행 증거가 있는 경우에만 통과로 판정합니다.

06제약사항과 확장

  • 정수예제 Class0 출력만으로 MNIST 실제 숫자 인식 성공을 주장하지 않는다.
  • 전체 28×28 영상은 12장 BRAM 64개 제한이 있으므로 타일 설계를 확인한다.
  • 디스플레이에 표시하는 클래스는 모델 ID 및 추론 완료에 해당하는 값이어야 한다.

07종합과제 · 공통 SoC 이어받기와 보드 확인

① 그대로 유지할 시스템

27장 검증된 NPU SoC와 18장 동일 모델의 MNIST 정밀도 실습

② 이번 종합과제의 추가 기능

PC 손글씨/이미지 전처리 데이터를 NPU에 전송해 실제 CLASS0~9, Score, UART/FND 결과를 한 시험 ID로 연결

③ 실습·실제 보드 확인

같은 이미지·가중치로 Python Class와 UART/LED/FND 표시가 일치하는지 보드 관측 후 시험 로그 보관

④ 완성 후 보존할 산출물

29장부터 응용별로 재사용할 수정 없는 27장 SoC 기준선

28~31장 종합과제 분기·센서·모터·암호 장치의 보드 확인 기준. 공통 NPU SoC에 임의로 위험 제어를 결합하지 않는다.
