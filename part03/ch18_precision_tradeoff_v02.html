동일한 입력을 Float·INT8·INT16으로 추론해 반올림·포화·클래스 일치 여부를 비교합니다.

정수 오차단계형 실습PC 기준값 비교

00과제 개요

동일한 입력을 Float·INT8·INT16으로 추론해 반올림·포화·클래스 일치 여부를 비교합니다.

선수학습: 05·06장 고정소수점, 15~17장 기준모델

산출물: 포화·반올림 정수 경계 시험과 비교 보고표

01구조와 데이터 흐름

정확도 비교와 FPGA 자원 비교는 같은 평가 집합에서 별도 수행합니다.

02핵심 설계 규격

  • Scale/Zero-point/Shift와 Half-away-from-zero 반올림 규칙을 먼저 고정한다.
  • INT8 출력 포화범위는 -128..127, signed INT16은 -32768..32767이다.
  • INT8 사용이 DSP 수·전력·속도를 일정 비율 줄인다고 단정하지 않는다.
  • 실제 정확도는 학습된 가중치와 동일 시험 데이터셋이 있어야 계산할 수 있다.

03실습 절차

  1. 동일한 입력을 정수화하기 전·후로 기록한다.
  2. 절반값 음수/양수 반올림과 두 경계의 포화를 시험한다.
  3. 시험집합에서 Accuracy 및 클래스 혼동행렬을 만들고 실제 측정 환경을 명시한다.
  4. Vivado 실제 자원·타이밍 데이터가 확보된 뒤 정밀도별 차이를 추가한다.

04구현 및 확인 코드

독립 기준모델 또는 실습 코드이며, 실제 FPGA 배치·동작 검증과는 별개입니다.

18장 Python 양자화 경계 · python
from part03.host_tools.p3_integer_reference import (
    round_shift_away, sat_int8,
)
v = [-5,-3,-1,0,1,3,5]
r = [round_shift_away(x,1) for x in v]
assert r == [-3,-2,-1,0,1,2,3]
assert sat_int8(-999) == -128
assert sat_int8(999) == 127
print(r)

예상 출력

[-3, -2, -1, 0, 1, 2, 3]

05검증 및 실습 점검

  • 반올림 절반값 부호 대칭성과 INT8 포화값을 검사한다.
  • INT8·INT16 학습/평가 데이터가 동일한지 확인한다.
  • 하드웨어 자원은 Vivado 보고값과 추정값을 구분한다.

Python 호스트 정답, RTL 시뮬레이션, Vivado 합성·타이밍, 실물 관찰은 별도 검증으로 기록합니다.

06오류를 피하는 기준

  • Python round() 반올림과 하드웨어 Shift 반올림은 같지 않을 수 있다.
  • 학습 Float 모델의 가중치를 단순 형변환하면 일반적인 양자화 정확도라고 볼 수 없다.
  • 정수모델 통과는 FPGA DSP 추론/타이밍을 확인한 것이 아니다.
