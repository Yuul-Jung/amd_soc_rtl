BASYS3 · MicroBlaze V · 제3부 23/31

제23장 · CPU 소프트웨어와 NPU 추론 성능 비교

동일 정수 모델을 CPU 계산과 NPU 가속으로 실행하고 계산 지연과 UART/AXI 전송 지연을 분리합니다.

지연·처리량기능 분리검증 절차

00과제 개요

동일 정수 모델을 CPU 계산과 NPU 가속으로 실행하고 계산 지연과 UART/AXI 전송 지연을 분리합니다.

선수학습: 22장 실제 Vitis 드라이버, 19장 이론 성능

산출물: 동일 모델·입력·정밀도의 CPU/FPGA 비교표

01시스템 구조

FPGA 내부 MAC 지연만 측정하면 전송·모델 적재를 포함한 사용자 체감 추론 지연보다 작을 수 있습니다.

02핵심 설계 계약

  • 정확도와 실행시간 비교에 동일 입력·가중치·바이어스·정수화 규칙을 쓴다.
  • CPU 기준은 컴파일 옵션과 실제 MicroBlaze V ISA 구성, NPU는 실제 클록/타일 횟수를 기록한다.
  • 모델 적재 시간, 입력 전송, 순수 연산, 결과 송신을 분리해 기록한다.
  • Latency, Throughput, Speedup, Energy는 서로 다른 지표다.

03따라 하기 실습

  1. CPU만으로 64→8→10 정수 모델을 실행하는 기준 루틴을 작성한다.
  2. 같은 모델을 NPU로 실행한 뒤 동일 정수 Score가 나오는지 확인한다.
  3. 성능 카운터/Timer로 CPU 및 NPU 시작·완료 차이를 측정한다.
  4. UART/AXI 모델 적재·입력 전송 시간을 포함한 End-to-End 측정도 별도로 수행한다.
  5. 10회 이상 반복 측정한 중간값과 최소·최대값을 기록한다.

04코드·설정 예제

측정된 실제 사이클을 입력한 후 계산한다. 아래 값은 형식 확인용 가상 예제다. 이 코드는 실습용 예제이며 실제 Vivado·Vitis 빌드 성공과 구분합니다.

성능 지표 계산 예제 · python
cpu_cycles = 10000   # 예시값: 실제 측정 후 교체
npu_cycles = 2000    # 예시값: 실제 측정 후 교체
clock_hz = 100_000_000
cpu_us = cpu_cycles / clock_hz * 1e6
npu_us = npu_cycles / clock_hz * 1e6
print("example speedup=", cpu_us/npu_us)

예상 출력·확인 조건

example speedup= 5.0

05검증 항목

  • 동일 정수 Score를 확인한 측정만 성능 비교에 포함한다.
  • 입력 전송 시간 포함/제외 조건을 각각 기록한다.
  • 캐시·인터럽트·타이머 분해능·CPU 부하에 따른 변동을 명시한다.

호스트 계산, RTL Simulation, Synthesis·Timing, Basys3 실물 게이트의 증거를 서로 구분해 기록합니다.

06오류·확장 경계

  • 위 5.0배는 예시 숫자이며 실제 FPGA 결과가 아니다.
  • CPU 클록과 NPU 클록이 다르면 서로 다른 Hz로 변환한다.
  • 제4부에서 다룰 전체 SoC 최적화/시스템 버스 성능과 범위를 구분한다.
