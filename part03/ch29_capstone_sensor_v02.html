진동·온도·거리 등 서로 다른 센서 특징을 정수 NPU에 입력하여 산업 설비 상태를 분류하고 경보를 표시합니다.

종합 2 · 산업안전종합 제작과제독립 검증

00과제 개요

진동·온도·거리 등 서로 다른 센서 특징을 정수 NPU에 입력하여 산업 설비 상태를 분류하고 경보를 표시합니다.

선수학습: 27장 NPU SoC, 제2부 센서·PWM·UART 과제

산출물: 센서 특징 벡터→상태 클래스→LED/FND/UART·안전 상태 시험

01시스템 구조

먼저 Python 생성/파일 입력의 가상 센서 벡터로 검증하고, 외부 하드웨어는 3.3V·전원·레벨시프터를 검토한 뒤 연결합니다.

02핵심 설계 규칙

  • 예시 클래스는 NORMAL·WARNING·FAULT·UNKNOWN 4종이며 실제 설비 라벨 데이터가 확보되기 전에는 교육용 분류다.
  • 온도·진동·거리의 단위와 스케일을 하나의 정수 입력에 무차별 혼합하지 않는다.
  • 값 누락·센서 고장·지연·범위 밖 입력은 UNKNOWN/FAULT 등 보수적 별도 상태로 처리한다.
  • 안전 관련 정지 출력은 NPU 예측만으로 제어하지 않고 독립 보호회로·인터록을 우선한다.
  • 산업 안전 성능/규격 적합성·현장 실증은 별도 평가다.

03따라 하기 실습

  1. 센서 3종의 명칭·단위·안전한 입력전압·읽기 주기를 표로 정의한다.
  2. 가상 예제 값을 고정된 정수 특징벡터로 변환한다.
  3. 상태 NORMAL/WARNING/FAULT/UNKNOWN을 코드와 비트표시 정책으로 정의한다.
  4. 센서 타임아웃·CRC 실패·연결 해제와 UNKNOWN 상태 전이를 시험한다.
  5. 각 모델 출력은 UART 로깅으로 남기고 실제 위험 장치 제어와 분리한다.

04코드 및 처리 기준

NPU 모델과 무관한 기본 센서 유효성 검사 예제이다. 안전을 위한 입력 실패 처리는 AI 출력보다 먼저 수행한다.

29장 센서 입력의 오류 우선 처리 · python
def evaluate(sample):
    # None이면 최신 측정값이 없다는 뜻
    if any(v is None for v in sample):
        return "UNKNOWN"
    temp_c, vibration, distance_cm = sample
    if not (-20 <= temp_c <= 100 and
            0 <= vibration <= 100 and
            2 <= distance_cm <= 400):
        return "FAULT"
    return "MODEL_INPUT_READY"

assert evaluate((None, 10, 60)) == "UNKNOWN"
assert evaluate((150, 10, 60)) == "FAULT"
print(evaluate((23, 10, 60)))

05동작 및 안전 검증

  • 결측·이상 범위·센서 수신 타임아웃을 AI 예측과 독립 검출한다.
  • CLASS와 경보 우선순위, FND 자리의 표시 의미를 고정한다.
  • 제어 출력의 안전한 기본값, 리셋, 전원 순간 강하 시 상태를 검증한다.

시뮬레이션·합성·실물 확인은 실제 실행 증거가 있는 경우에만 통과로 판정합니다.

06제약사항과 확장

  • 예시 센서의 합성 데이터 분류를 산업 현장 안전성 보증이라고 부르지 않는다.
  • 초음파 Echo 5V 등 외부 입력은 3.3V 변환 회로와 별도 전원을 검증한다.
  • 제2부 센서/모터 IP를 그대로 재사용하되 Top에는 복합 우선순위 판단을 두지 않는다.
