BASYS3 · MicroBlaze V · 제3부 20/31

제20장 · AXI4-Lite NPU 제어 IP

독립 NPU 코어를 AXI4-Lite 제어·상태 레지스터와 연결하여 CPU가 실행을 제어하도록 설계합니다.

AXI 레지스터기능 분리검증 절차

00과제 개요

독립 NPU 코어를 AXI4-Lite 제어·상태 레지스터와 연결하여 CPU가 실행을 제어하도록 설계합니다.

선수학습: 12장 npu_engine4, 제1~2부 AXI IP

산출물: 동기식 제어 Register Map, 읽기/쓰기/Busy/DONE/Error 계약

01시스템 구조

제어 레지스터는 AXI4-Lite로 접근하고 많은 입력·가중치의 공급 방식은 별도로 설계합니다. 기존 성공 SoC의 주소맵을 변경하지 않습니다.

02핵심 설계 계약

  • CTRL START는 1클록 펄스 또는 write-one pulse로 취급한다. STATUS는 BUSY, DONE, ERROR을 분리하고 DONE clear 정책을 정의한다.
  • 주소는 32비트 aligned 오프셋. 주소 범위와 실제 베이스 주소는 Vivado Address Editor의 할당값을 사용한다.
  • AW와 W 채널은 서로 독립적으로 도착할 수 있으므로 항상 같은 클록에 나타난다고 가정하지 않는다.
  • WSTRB 바이트 인에이블, B/R 응답 역압력, Reset 중 요청 처리 및 유효하지 않은 주소 접근을 시험한다.
  • signed 41비트 이상의 결과를 32비트 레지스터 2개로 노출할 경우 데이터 일관성 확보 규칙을 정한다.

03따라 하기 실습

  1. CTRL 0x00, STATUS 0x04, LENGTH 0x08, CLASS 0x0C의 최소 레지스터를 정의한다.
  2. INPUT/WEIGHT/Bias 주소·데이터와 SCORE 선택/읽기 레지스터를 추가하여 읽기·쓰기 순서를 문서화한다.
  3. Tools → Create and Package New IP에서 AXI4-Lite 주변장치 템플릿을 생성하고 기존 독립 npu_engine4를 하위 인스턴스로 연결한다.
  4. 주소 채널·데이터 채널의 비동기 도착·Backpressure·오류 응답을 독립 Testbench로 검증한다.
  5. 실제 연결 전에는 임의 베이스 주소를 Vitis 코드에 하드코딩하지 않는다.

04코드·설정 예제

레지스터 표의 초안은 다음의 오프셋을 쓰며 모든 값은 32비트이다. 이 코드는 실습용 예제이며 실제 Vivado·Vitis 빌드 성공과 구분합니다.

제어 레지스터 오프셋 표 · text
0x00 CTRL      bit0 START(write-one pulse)
0x04 STATUS    bit0 BUSY, bit1 DONE, bit2 ERROR
0x08 LENGTH    unsigned, 별도 최대값 검증
0x0C CLASS     0..9
0x10 X_INDEX   데이터 인덱스
0x14 X_DATA    signed 입력값
0x18 W_CLASS   가중치 행 번호
0x1C W_INDEX   해당 행 인덱스
0x20 W_DATA    signed 가중치값
0x24 BIAS_LO   하위 32비트
0x28 BIAS_HI   상위 부호 확장 비트
0x2C SCORE_SEL 읽을 클래스
0x30 SCORE_LO  결과 하위 32비트
0x34 SCORE_HI  결과 상위 부호 확장
0x38 IRQ_EN    인터럽트 허용

05검증 항목

  • AW/W 독립 도착 및 BREADY=0 상태의 응답 보존.
  • AR/RREADY 역압력과 요청 순서 및 Read-Only 레지스터 쓰기 보호.
  • START while BUSY, 미적재 모델, RESET, 잘못된 LEN 및 주소.
  • SCORE_LO/HI는 같은 완료 결과의 Snapshot이어야 한다.

호스트 계산, RTL Simulation, Synthesis·Timing, Basys3 실물 게이트의 증거를 서로 구분해 기록합니다.

06오류·확장 경계

  • AXI4-Lite는 대량 모델 전송의 고속 버스로 간주하지 않는다.
  • 제2부의 AXI 실습 IP를 무작정 복사하지 않고 기존 검증 컨트롤러/BD 재사용 범위를 확인한다.
  • 정의한 오프셋은 신규 교육용 계약이며 실제 원본 SoC 주소가 아니다.
