제13장 · 8×8 손글씨 입력과 숫자 10분류

MNIST의 원본 28×28 영상을 8×8 특징으로 축소하고 0~9 분류 인터페이스를 준비합니다.

MNIST 입출력단계형 실습PC 기준값 비교

00과제 개요

MNIST의 원본 28×28 영상을 8×8 특징으로 축소하고 0~9 분류 인터페이스를 준비합니다.

선수학습: 12장 4분류 NPU, Python 배열 처리

산출물: 64특징 벡터·숫자 라벨의 표준 전처리 방식

01구조와 데이터 흐름

28×28 입력을 그대로 추론하는 모델과 8×8으로 줄인 모델은 서로 다른 데이터 처리 조건입니다.

02핵심 설계 규격

  • 원본 [1,28,28] → 축소 [1,8,8] → 64개 입력. 숫자 분류는 0~9의 10개 클래스다.
  • 12장 NPU는 4뉴런 분류와 최대 64개 원소만 처리하므로 10개 점수를 바로 출력하지 못한다.
  • 평균 풀링 크기·데이터 정규화·학습/시험 집합의 분리 규칙을 고정한다.
  • 이미지 축소만으로 성능·정확도가 개선된다고 주장하지 않는다.

03실습 절차

  1. torchvision MNIST의 train=False 시험 데이터와 ToTensor 전처리를 준비한다.
  2. adaptive_avg_pool2d를 사용하여 28×28을 8×8으로 축소한다.
  3. 64개 값과 실제 라벨을 확보하고 최솟값·최댓값을 확인한다.
  4. 향후 64→10과 64→8→10 모델이 동일 전처리를 사용하게 한다.

04구현 및 확인 코드

독립 기준모델 또는 실습 코드이며, 실제 FPGA 배치·동작 검증과는 별개입니다.

13장 Python 전처리 예제 · python
import torch
from torchvision.datasets import MNIST
from torchvision.transforms import ToTensor

data = MNIST("data/mnist", train=False,
             transform=ToTensor(), download=True)
image, label = data[0]                    # [1,28,28]
small = torch.nn.functional.adaptive_avg_pool2d(
    image.unsqueeze(0), (8,8))[0]         # [1,8,8]
x = small.reshape(64)
assert x.numel() == 64 and 0 <= int(label) <= 9
print("shape=", tuple(x.shape))

예상 출력

shape= (64,)

05검증 및 실습 점검

  • Tensor shape, 라벨 0~9, 값 범위 [0,1] 검사.
  • 학습/시험 샘플의 구분을 확인하고 입력 스케일을 문서화한다.
  • FPGA의 10클래스 결과는 신규 구현 후 별도 시뮬레이션으로 검증한다.

Python 호스트 정답, RTL 시뮬레이션, Vivado 합성·타이밍, 실물 관찰은 별도 검증으로 기록합니다.

06오류를 피하는 기준

  • 8×8 결과를 28×28 실험 정확도로 표기하지 않는다.
  • 처음 MNIST를 내려받을 때는 네트워크 접속이 필요하다.
  • 현행 12장 4클래스 데모를 MNIST 실제 분류 실험으로 혼동하지 않는다.
