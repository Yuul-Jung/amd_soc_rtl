핵심 주제: 신편 P1-11 · 사용자 Top·SW0→LED0

Block Design과 Vivado가 만든 Wrapper는 CPU·IP의 내부 연결을 담당합니다. basys3_soc11_top은 그 바깥에서 보드 핀과 Wrapper를 연결하는 순수 Shell로 유지하고, 기능 판단은 CPU C 코드/하위 IP에서 수행합니다.

실습을 말로 풀기: basys3_soc11_top → u_soc11 : soc11_integration_wrapper → soc11_integration_i : soc11_integration → AXI GPIO → SW0/LED0 흐름을 확인합니다.

확인 범위: 10장 전체 동등성까지 요구하지 않습니다. 사용자 제공 2026-11-02 보드 동작 확인 범위와 신규 재실행 여부를 분명히 구분합니다.

SECTION 02실습 준비

프로젝트 복제 → Wrapper 포트 확인

  1. Vivado 2024.2를 실행하고 File → Project → Open에서 /home/jung/soc/hw/soc10_integration/soc10_integration.xpr을 엽니다.
  2. File → Project → Save As로 프로젝트 이름을 soc11_user_top으로 지정합니다. 결과 경로는 /home/jung/soc/hw/soc11_user_top/soc11_user_top.xpr이 되도록 Project Summary에서 확인합니다.
  3. Sources → Hierarchy에서 기존 soc10_integration.bd를 더블클릭해 열고 File → Save Block Design As를 선택합니다. Design name을 soc11_integration, Directory를 <Local to Project>, Add to source set을 Design Sources로 지정하고 OK를 클릭합니다.
  4. Sources → Design Sources에서 새 soc11_integration.bd를 확인합니다. 새 BD를 열어 Validate Design을 실행하고 Address Editor에서 GPIO·UART·Timer·INTC·BRAM 주소가 유지되는지 확인합니다.
  5. 새 soc11_integration.bd를 오른쪽 클릭 → Generate Output Products를 실행합니다. 이어 Create HDL Wrapper → Let Vivado manage wrapper and auto-update를 선택하여 soc11_integration_wrapper.v를 생성합니다. 생성 파일의 이름만 수동 변경하지 않습니다.
  6. soc11_integration_wrapper.v의 module soc11_integration_wrapper (...)에서 포트명·방향·비트폭을 확인합니다. 10장 실제 XDC의 sw_tri_i, led_tri_o, UART_0_rxd, UART_0_txd를 기준으로 대조합니다. 다르면 실제 생성 포트에 맞춰 사용자 Top 연결만 수정합니다.
  7. Constraints → 현재 Basys-3-Master.xdc 열기. 기존 get_ports {sw_tri_i[n]} / {led_tri_o[n]} 제약은 새 Top의 sw[n] / led[n]과 이름이 맞지 않으므로 11장 XDC로 교체합니다.
  8. Add Sources → Add or Create Constraints → Add Files에서 basys3_soc11_top.xdc를 추가합니다. Constraints에서 기존 Basys-3-Master.xdc의 Enabled를 해제하여 동일 핀/Clock 제약이 중복 적용되지 않게 합니다.
  9. 새 XDC의 get_ports가 Top 포트명과 일치하는지 확인합니다. clk=W5, btnC=U18, sw[13]=U1, led[13]=N3, RsRx=B18, RsTx=A18입니다.
  10. Block Design → Address Editor를 열어 GPIO, UART Lite, Timer, INTC 기존 주소 및 BRAM 64 KiB가 그대로인지 확인하고 저장합니다.

SECTION 04Vitis · C

SW0 입력을 LED0에 표시

① 11장 XSA로 Platform 준비

  1. Vivado에서 File → Export → Export Hardware로 내보낸 11장 XSA(Include Bitstream)의 파일 위치를 확인합니다. 10장 원본 XSA를 선택하지 않습니다.
  2. Vitis Unified IDE 2024.2에서 Workspace ~/soc/sw를 엽니다. 기존 10장 Application은 변경하지 않습니다.
  3. 새 Platform이 없는 경우: File → New Component → Platform을 선택합니다. Component name에 soc11_user_top_platform을 입력하고 Next를 누릅니다.
  4. Hardware Design → Browse에서 방금 만든 11장 XSA 파일을 선택합니다. Operating System은 standalone, Processor는 microblaze_riscv_0를 지정하여 Finish합니다. Domain 이름은 생성된 화면의 실제 값을 확인합니다.
  5. 이미 11장 Platform이 있는 경우: 해당 Platform의 Settings → vitis-comp.json → Switch XSA로 새 11장 XSA를 지정합니다. 10장 Platform 자체는 변경하지 않습니다.
  6. Vitis Explorer에서 soc11_user_top_platform [Platform]을 선택하고 Flow → Build를 실행합니다. Build 완료 메시지와 Output의 Platform 생성 파일을 확인합니다.

② 11장 Application 생성

  1. File → New Component → Application을 선택하고 Empty Application을 준비합니다.
  2. Name and Location에서 Component name을 soc11_user_top_app으로 지정하고 Next를 누릅니다. 기존 10장 Application과 서로 다른 이름을 사용합니다.
  3. Select Platform에서 방금 빌드한 soc11_user_top_platform을 선택한 뒤 Next를 누릅니다.
  4. Select Domain에서 standalone·microblaze_riscv_0에 해당하는 Domain(예: standalone_microblaze_riscv_0)을 선택합니다. 실제 생성된 이름이 다르면 화면의 이름을 사용합니다.
  5. Source Files는 빈 Application으로 진행하고 Summary → Finish를 클릭합니다. Explorer에 soc11_user_top_app [Application]이 생성되는지 확인합니다.

③ BSP와 BRAM 설정 확인

  1. 새 Platform의 BSP → include → xparameters.h에서 AXI GPIO 0x4000_0000, UART Lite 0x4060_0000, INTC 0x4120_0000, Timer 0x41C0_0000 주소를 확인합니다. BSP의 매크로 명칭은 생성된 파일 기준으로 확인합니다.
  2. 새 Application의 Sources → src → lscript.ld를 열어 Local BRAM이 ORIGIN 0x00000000, LENGTH 0x10000(64 KiB)인지 확인합니다. 실제 메모리 영역 이름은 생성 결과를 사용합니다.
  3. 주소 또는 메모리 크기가 다르면 Platform이 선택한 XSA부터 확인합니다. 링커 숫자를 임의로 바꾸거나 기존 10장 소스를 수정하지 않습니다.

④ main.c 작성

  1. soc11_user_top_app → Sources → src에서 main.c를 열거나, 파일이 없으면 src 오른쪽 클릭 → New File → main.c를 생성합니다.
  2. 아래 11장 Vitis C 전체 코드를 src/main.c에 입력한 뒤 Ctrl+S로 저장합니다. Application 안에 main() 함수가 두 개 생기지 않도록 합니다.
  3. SW_LED_MASK가 0x00000001U인지 확인합니다. 이 값은 SW0 → LED0 예시이며, 다른 포트 배치 실습은 사용자 Top의 배선과 소프트웨어 역할을 구분해서 변경합니다.

/*
 * SoC 11 - 사용자 Top 기반 MicroBlaze V + GPIO/UART/Timer/INTC 실습
 *
 * GPIO Channel 1 : LED[15:0] output
 * GPIO Channel 2 : SW[15:0] input
 *
 * LED ownership:
 *   LED0      : SW0 mirror (SW_LED_MASK의 bit0만 사용)
 *   LED[13:1] : 현재 C 출력에서는 0 (하드웨어 핀은 분리하지 않음)

 *   LED15     : Timer interrupt heartbeat

#define GPIO_SW_CHANNEL         2U

// (변경) 11장 독립 실습: 스위치 한 비트(SW0)만 LED0에 반영
#define SW_LED_MASK             0x00000001U
// (유지) bit14=UART 표시, bit15=Timer 표시. SW_LED_MASK와 비트 중복 금지
#define UART_LED_MASK           0x00004000U
#define HEARTBEAT_LED_MASK      0x00008000U

#define TIMER0                  0U
// (유지) 100 MHz 기준 0.5초에 해당하는 50,000,000 tick
#define TIMER_TICKS_500MS       50000000U
#define TIMER_RESET_VALUE       (TIMER_TICKS_500MS - 2U)

// (참고) 사용 중인 Vitis BSP의 SDT 여부에 따라 장치 식별자/기준 주소 선택
#ifndef SDT
#define GPIO_DEVICE_ID          XPAR_GPIO_0_DEVICE_ID
#define TIMER_DEVICE_ID         XPAR_TMRCTR_0_DEVICE_ID
#define INTC_DEVICE_ID          XPAR_INTC_0_DEVICE_ID
#define TIMER_INTERRUPT_ID      XPAR_INTC_0_TMRCTR_0_VEC_ID
#define UART_BASEADDR           XPAR_UARTLITE_0_BASEADDR
#else
#define GPIO_BASEADDR           XPAR_XGPIO_0_BASEADDR
#define TIMER_BASEADDR          XPAR_XTMRCTR_0_BASEADDR
#define UART_BASEADDR           XPAR_XUARTLITE_0_BASEADDR
#endif

static XGpio Gpio;
static XTmrCtr Timer;

#ifndef SDT
static XIntc Intc;
#endif

// (유지) 인터럽트에서 변경되는 공유 카운터
volatile u32 interrupt_count = 0U;
volatile u32 switch_value    = 0U;
volatile u32 led_state       = 0U;
volatile u8  last_uart_rx    = 0U;

static u32 uart_led_state = 0U;

// (유지) UART Lite 바이트 전송용 최소 출력 함수
static void UartPutChar(u8 ch)
{
    XUartLite_SendByte(UART_BASEADDR, ch);
}

static void UartPutString(const char *text)
{
    while (*text != '\0') {
        UartPutChar((u8)*text);
        text++;
    }
}

static void UartPutHexNibble(u8 value)
{
    value &= 0x0FU;

    if (value < 10U) {
        UartPutChar((u8)('0' + value));
    } else {
        UartPutChar((u8)('A' + (value - 10U)));
    }
}

static void UartPutHex16(u16 value)
{
    int shift;

    for (shift = 12; shift >= 0; shift -= 4) {
        UartPutHexNibble((u8)(value >> shift));
    }
}

static void UartPutHex32(u32 value)
{
    int shift;

    for (shift = 28; shift >= 0; shift -= 4) {
        UartPutHexNibble((u8)(value >> shift));
    }
}

static void PrintHelp(void)
{
    UartPutString("\r\nCommands\r\n");
    UartPutString("  1 : LED14 ON\r\n");
    UartPutString("  0 : LED14 OFF\r\n");
    UartPutString("  r : Read status\r\n");
    UartPutString("  h : Help\r\n");
}

// (유지) 터미널의 'r' 명령에 현재 SW/LED/IRQ 상태를 출력
static void PrintStatus(void)
{
    UartPutString("\r\nSW=0x");
    UartPutHex16((u16)switch_value);
    UartPutString(" LED=0x");
    UartPutHex16((u16)led_state);
    UartPutString(" IRQ=0x");
    UartPutHex32(interrupt_count);
    UartPutString("\r\n");
}

// (유지) Timer 인터럽트 콜백은 카운트만 증가시켜 실행 시간을 최소화
static void TimerCallback(void *CallBackRef, u8 TmrCtrNumber)
{
    (void)CallBackRef;
    (void)TmrCtrNumber;
    interrupt_count++;
}

// (유지) AXI GPIO 드라이버 초기화; 채널 방향은 기존 BD 설정을 사용
static int InitGpio(void)
{
#ifndef SDT
    return XGpio_Initialize(&Gpio, GPIO_DEVICE_ID);
#else
    return XGpio_Initialize(&Gpio, GPIO_BASEADDR);
#endif
}

// (유지) Timer SelfTest → 콜백 등록 → Down Count/Auto Reload/IRQ 설정
static int InitTimer(void)
{
    int status;

#ifndef SDT
    status = XTmrCtr_Initialize(&Timer, TIMER_DEVICE_ID);
#else
    status = XTmrCtr_Initialize(&Timer, TIMER_BASEADDR);
#endif

    if (status != XST_SUCCESS) {
        return XST_FAILURE;
    }

    status = XTmrCtr_SelfTest(&Timer, TIMER0);
    if (status != XST_SUCCESS) {
        return XST_FAILURE;
    }

    XTmrCtr_SetHandler(&Timer, TimerCallback, &Timer);
    XTmrCtr_SetOptions(
        &Timer,
        TIMER0,
        XTC_DOWN_COUNT_OPTION |
        XTC_AUTO_RELOAD_OPTION |
        XTC_INT_MODE_OPTION
    );
    XTmrCtr_SetResetValue(&Timer, TIMER0, TIMER_RESET_VALUE);

    return XST_SUCCESS;
}

// (유지) AXI INTC/CPU 인터럽트를 Timer 인터럽트 핸들러와 연결
static int SetupInterruptSystem(void)
{
    int status;

#ifndef SDT
    status = XIntc_Initialize(&Intc, INTC_DEVICE_ID);
    if (status != XST_SUCCESS) {
        return XST_FAILURE;
    }

    status = XIntc_Connect(
        &Intc,
        TIMER_INTERRUPT_ID,
        (XInterruptHandler)XTmrCtr_InterruptHandler,
        (void *)&Timer
    );
    if (status != XST_SUCCESS) {
        return XST_FAILURE;
    }

    status = XIntc_Start(&Intc, XIN_REAL_MODE);
    if (status != XST_SUCCESS) {
        return XST_FAILURE;
    }

    XIntc_Enable(&Intc, TIMER_INTERRUPT_ID);

    Xil_ExceptionInit();
    Xil_ExceptionRegisterHandler(
        XIL_EXCEPTION_ID_INT,
        (Xil_ExceptionHandler)XIntc_InterruptHandler,
        &Intc
    );
    Xil_ExceptionEnable();
#else
    status = XSetupInterruptSystem(
        &Timer,
        (XInterruptHandler)XTmrCtr_InterruptHandler,
        Timer.Config.IntrId,
        Timer.Config.IntrParent,
        XINTERRUPT_DEFAULT_PRIORITY
    );

    if (status != XST_SUCCESS) {
        return XST_FAILURE;
    }
#endif

    return XST_SUCCESS;
}

// (유지) UART RX/TX FIFO를 초기화하며 UART 자체 IRQ는 사용하지 않음
static void InitUart(void)
{
    /* RX/TX FIFO clear. UART interrupt remains disabled. */
    XUartLite_WriteReg(
        UART_BASEADDR,
        XUL_CONTROL_REG_OFFSET,
        0x03U
    );
}

// (유지) 폴링 방식으로 문자 '1'/'0'을 LED14 상태에 반영
static void HandleUartCommand(void)
{
    // 수신 데이터가 없으면 곧바로 반환해 SW 읽기·Timer 동작을 막지 않음
    if (XUartLite_IsReceiveEmpty(UART_BASEADDR)) {
        return;
    }

    last_uart_rx = XUartLite_RecvByte(UART_BASEADDR);

    switch (last_uart_rx) {
    case '1':
        uart_led_state = UART_LED_MASK;
        UartPutString("\r\nLED14=ON\r\n");
        break;

    case '0':
        uart_led_state = 0U;
        UartPutString("\r\nLED14=OFF\r\n");
        break;

    case 'r':
    case 'R':
        PrintStatus();
        break;

    case 'h':
    case 'H':
        PrintHelp();
        break;

    case '\r':
    case '\n':
        break;

    default:
        UartPutString("\r\nUnknown command. Press h.\r\n");
        break;
    }
}

// (핵심) SW0, UART 명령, Timer heartbeat의 비트를 합쳐 LED 출력 계산
static void UpdateLedOutput(void)
{
    u32 new_led_state;
    u32 heartbeat_state;

    if ((interrupt_count & 1U) != 0U) {
        heartbeat_state = HEARTBEAT_LED_MASK;
    } else {
        heartbeat_state = 0U;
    }

    // SW0(bit0) + UART(bit14) + Timer(bit15)를 비트 OR로 합침
    // sw[15:1] 입력은 유지하지만 현재 LED1~13에는 출력하지 않음
    new_led_state =
        (switch_value & SW_LED_MASK) |
        uart_led_state |
        heartbeat_state;

    // LED 값이 실제로 바뀌었을 때만 AXI GPIO 출력 레지스터에 기록
    if (new_led_state != led_state) {
        led_state = new_led_state;
        XGpio_DiscreteWrite(
            &Gpio,
            GPIO_LED_CHANNEL,
            led_state
        );
    }
}

// (핵심) GPIO/UART/Timer/Interrupt를 준비한 뒤 입력→출력을 반복
int main(void)
{
    int status;

    status = InitGpio();
    if (status != XST_SUCCESS) {
        return XST_FAILURE;
    }

    InitUart();

    status = InitTimer();
    if (status != XST_SUCCESS) {
        return XST_FAILURE;
    }

    status = SetupInterruptSystem();
    if (status != XST_SUCCESS) {
        return XST_FAILURE;
    }

    led_state = 0U;
    XGpio_DiscreteWrite(&Gpio, GPIO_LED_CHANNEL, led_state);

    UartPutString("\r\nSoC 10 Integrated System Ready\r\n");
    PrintHelp();

    XTmrCtr_Start(&Timer, TIMER0);

    // SW 값을 읽고 → UART 명령 처리 → 최종 LED 값을 출력하는 메인 루프
    while (1) {
        switch_value = XGpio_DiscreteRead(
            &Gpio,
            GPIO_SW_CHANNEL
        );

        HandleUartCommand();
        UpdateLedOutput();
    }

    return XST_SUCCESS;
}

⑤ Platform·Application Build 및 ELF 확인

  1. Vitis Explorer에서 soc11_user_top_platform이 새 XSA로 Build 완료됐는지 확인합니다. XSA를 다시 지정한 경우 Platform을 먼저 Rebuild합니다.
  2. soc11_user_top_app을 선택하고 Flow → Build를 실행합니다. 빌드 로그의 Build Finished successfully 메시지와 Output에 생성된 soc11_user_top_app.elf를 확인합니다.
  3. ELF가 생성되지 않으면 Console의 첫 번째 컴파일·링커 오류와 xparameters.h, lscript.ld, 선택한 Domain을 확인합니다. 빌드 완료를 임의로 가정하지 않습니다.

⑥ FPGA 다운로드 · ELF 실행

  1. Vivado Hardware Manager → Open Target → Program Device에서 11장 사용자 Top으로 생성한 새 Bitstream을 Basys3에 다운로드합니다.
  2. Vitis에서 soc11_user_top_app의 Run/Debug 설정(launch.json)을 열어 대상 하드웨어와 새 .elf를 선택하고 Run 또는 Debug를 실행합니다.
  3. Ubuntu moserial에서 115200, 8N1, Flow Control Off로 USB-UART 포트를 열고, 시작 메시지·1/0/r 명령과 아래 보드 출력을 확인합니다.
