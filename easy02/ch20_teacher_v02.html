00과제 개요와 완료 기준

제20장은 제2부 11~19장의 개별 RTL 기능을 결합하여 독립 기능 제어에서 시스템 단위 이벤트·표시·구동 제어로 확장하는 종합 과제다. 기존 성공 프로젝트·RTL을 변경하지 않고, 이미 만든 모듈을 상위에서 연결하는 방식으로 진행한다.

이번 실습은 실제 12.4장 스테핑 모터, 18장 PIR 입력/IRQ, 19장 환경 정책 RTL 파일을 그대로 컴파일하고 새 soc20_safety_supervisor.v를 연결해 종합 동작을 검증한다.

완료 범위 한정: 세 기존 RTL의 기능 통합 RTL_SIM PASS. RFID·LCD·RTC·BME280의 통신 회로 및 실제 AXI4-Lite/MicroBlaze V 전체 SoC 결합, Vivado 합성·타이밍·Vitis 타깃·실물 동작은 미구현 또는 미검증 상태다. Full SoC 검증은 완료되지 않았다.

01계층별 복합 SoC 구조도

그림의 environment_policy, pir_irq_controller, stepper_ramp_core는 각각 기존 19장·18장·12.4장의 RTL 원본이며, soc20_integrated_core가 이를 한 클록 도메인에서 직접 결합한다.

실제 기존 12.4장·18장·19장 RTL을 컴파일 경로에서 참조하므로 중복 정의 없이 설계가 누적된다. 아래에 P2-20 신규 계층과 자가검증 테스트벤치의 전체 원본을 모았다.

`timescale 1ns/1ps
// P2-20: Safety DEMO policy, NOT a certified safety function.
// Freshness applies to valid temperature sources, not to RTC/PIR.
// Fail-safe: no valid sample, stale sample, or active environment
// alarm disables actuator permit. Arm must be re-asserted after a
// loss of permit (latched trip) and a fresh sample must be present.
module soc20_safety_supervisor #(
    parameter integer MAX_AGE_CYCLES=100000000
)(
    input wire clk,input wire resetn,
    input wire sample_valid,
    input wire arm_request,
    input wire disarm_request,
    input wire fault_clear_pulse,
    input wire alarm_active,
    output wire actuator_permit,
    output reg fresh,
    output reg fault_latched,
    output reg [31:0] sample_age
);
    reg armed;
    assign actuator_permit = resetn && armed && fresh &&
                             !fault_latched && !alarm_active;
    always @(posedge clk) begin
        if(!resetn)begin
            armed<=0;fresh<=0;fault_latched<=0;sample_age<=0;
        end else begin
            if(sample_valid)begin
                fresh<=1;sample_age<=0;
            end else if(fresh)begin
                if(sample_age>=MAX_AGE_CYCLES-1)begin
                    fresh<=0;
                    fault_latched<=1;
                end else sample_age<=sample_age+1;
            end
            if(alarm_active) fault_latched<=1;
            // Clear a trip does not automatically restart actuators.
            // Need a separate arm_request after fault_clear.
            if(fault_clear_pulse && !alarm_active && fresh)begin
                fault_latched<=0;armed<=0;
            end
            if(disarm_request)armed<=0;
            else if(arm_request && fresh && !fault_latched &&
                    !alarm_active && !fault_clear_pulse)armed<=1;
            if(!fresh)armed<=0;
        end
    end
endmodule

            @(negedge clk);page_next=0;

        $display("P2_20_INTEGRATED_SOC_RTL PASS");
        $finish;
    end

08핵심 정리

① 기존 RTL을 실제 재사용한다. 단계별로 합격한 개별 Core를 변경하지 않고 통합 계층에서 결합한다.

② 센서 Valid만으로 안전하다고 가정하지 않는다. 새 데이터의 유효기간, 인터럽트, 경보, 출력 재시작 정책을 구별한다.

③ 모의 통합과 실제 전체 SoC를 구분한다. 이번 시뮬레이션의 PASS는 3개 기존 RTL + 1개 신규 감독 정책의 제한된 범위다. RFID/LCD/RTC/I²C/AXI와 실물 전체는 통합 전 Gate로 남아 있다.
