00. 제02장 1교시 운영 · 60분

제01장에서 저장한 soc01_mb_bram.bd를 이어서 사용하여 100 MHz Clock(클록)과 Reset(리셋)을 실제 Basys3 입출력과 연결합니다. CPU·BRAM을 다시 만들지 않습니다.

시간진행 단계확인할 결과
0~10분제01장 BD 열기, 이전 회로 인계MicroBlaze V·BRAM·Clock/Reset IP 존재
10~23분100 MHz·10 ns·Locked·Reset 개념 설명입력 Clock과 생성 Clock 구분
23~38분clk_wiz_1 100 MHz 설정Single-ended 입력, clk_out1 확인
38~50분외부 clk, btnC 포트 연결W5·U18과 논리적 포트 대응
50~60분Processor System Reset과 핵심 배선 점검Lock→Reset→CPU 경로 확인
교수자 첫 설명: “01장에서는 CPU와 메모리를 연결했습니다. 그런데 CPU가 실제로 움직이려면 규칙적인 박자가 필요합니다. 그리고 버튼을 눌렀을 때 초기 상태로 돌아갈 수 있어야 합니다. 이번 시간에는 그 두 신호를 배선합니다.”

01. 기존 회로를 보존하는 이유

먼저 Vivado의 Sources → Design Sources에서 제01장에서 만든 soc01_mb_bram.bd를 더블클릭합니다. CPU를 새로 추가하거나 새로운 BD를 만들지 않습니다.

기존 항목1교시에서 하는 일교수자 쉬운 설명
microblaze_riscv_0그대로 유지“CPU는 이미 만들어 두었습니다. 오늘 CPU 내부 구조를 다시 설정하지 않습니다.”
Local Memory 16 KB그대로 유지“명령과 데이터를 담는 메모리의 크기도 유지합니다.”
clk_wiz_1입력 형태·주파수 확인“기준 Clock을 받아 CPU용 Clock을 공급하는 기능입니다.”
rst_clk_wiz_1_100M입력·출력 Reset 연결“Clock이 준비되었는지 확인하고 여러 회로의 초기화를 제어합니다.”
mdm_*Debug Reset 경로 확인“후속 디버깅에 필요한 기능을 유지합니다.”

질문: “01장 프로젝트를 이어서 쓰면 이미 만들었던 BRAM이 사라질까요?” → 아니요. 같은 BD에서 기존 구성은 유지하고 이번 기능만 연결합니다.

02. Clock과 Reset 전체 구조를 시각화

Clock은 회로가 동작하는 시간 기준이고, Reset은 동작을 시작할 초기 상태를 정하는 제어 신호입니다. Clock과 Reset은 같은 신호가 아닙니다. 각 경로를 색상 대신 이름과 화살표로 구분하며 설명합니다.

① clk에서 100 MHz 입력을 받습니다.

② clk_wiz_1이 clk_out1을 통해 내부 시스템 Clock을 공급합니다.

③ locked는 Clocking Wizard의 안정 상태를 알려 줍니다.

④ btnC는 사람이 누르는 외부 Reset 요청입니다.

⑤ rst_clk_wiz_1_100M가 Clock 상태·Reset 입력을 바탕으로 mb_reset 등 적절한 Reset 신호를 제공합니다.

03. 100 MHz와 10 ns를 계산하는 방법

f = 100 MHz = 100,000,000 Hz → T = 1/f = 10 ns

말로 풀이: “한 번의 클록 주기가 10나노초입니다. 1초 동안 같은 박자가 1억 번 되풀이됩니다.” MHz는 1초당 반복 횟수, ns는 시간입니다.

용어쉽게 설명이번 장 설정
Primary Clock(프라이머리 클록, 기준 입력 클록)보드에서 들어오는 기준 신호W5 · 100 MHz
Generated Clock(제너레이티드 클록, 내부 생성 클록)Clocking Wizard의 출력clk_out1 · 100 MHz
Single-ended(싱글 엔디드, 단일 신호선)한 개의 신호로 Clock을 전달하는 방식Basys3 W5에 적합
Differential(디퍼렌셜, 차동 신호)두 신호선의 차이로 신호를 전달하는 방식이번 입력에는 사용하지 않음
lockedClock 출력이 안정적으로 동작할 상태에 이르렀음을 알리는 신호Reset Controller에 전달

질문: “100 MHz 입력을 선택했다고 출력도 무조건 100 MHz일까요?” → 아닙니다. Clocking Wizard에서는 출력 주파수도 따로 설정·확인해야 합니다. 이번 실습은 100 MHz 출력입니다.

04. Clocking Wizard 설정 · 클릭 한 단계씩

작업입력·선택 값왜 필요한가
① Diagram에서 clk_wiz_1 더블클릭Clocking Wizard IP 설정 화면“Clock 설정은 CPU 본체가 아니라 Clocking Wizard에서 관리합니다.”
② Clocking Options 열기Primary Input Source“외부에서 들어오는 신호의 형태를 지정합니다.”
③ 입력 형태 선택Single ended clock capable pin“Basys3 W5에는 단일 100 MHz Clock이 들어옵니다.”
④ 입력 주파수 설정100.000 MHz“Clock 회로에 들어오는 신호 주파수를 알려 줍니다.”
⑤ 출력 설정 확인clk_out1 = 100 MHz“CPU와 BRAM이 사용할 시스템 Clock을 100 MHz로 확인합니다.”
⑥ CLK_IN1_D가 보이는 경우차동 입력 선택 여부를 확인 후 단일 입력으로 조정“차동 입력 포트로 남아 있다면 실제 보드의 단일 입력과 맞지 않을 수 있습니다.”
⑦ 저장Ctrl+S“설정만 하고 저장하지 않으면 회로 설계 파일에 반영되지 않습니다.”

화면에서 볼 결과: clk_wiz_1 설정에 100 MHz 입력과 100 MHz clk_out1 출력이 표시되고 차동 입력이 아닌 상태입니다.

05. 외부 Clock·Reset 포트와 보드 핀

① clk_wiz_1/clk_in1 입력 핀에서 우클릭하고 Make External을 선택합니다. 이미 연결된 외부 포트가 있다면 새로 만들지 않습니다.

② 만들어진 외부 포트가 clk인지 확인합니다. “clk는 회로의 바깥에 보이는 신호 이름이며 W5는 FPGA 패키지의 물리 핀입니다.”

③ clk_wiz_1/reset에 연결된 선을 확인하고 필요한 경우 외부 Reset 포트를 만듭니다. 이름은 btnC와 대응시킵니다.

④ 동일한 btnC 요청이 rst_clk_wiz_1_100M/ext_reset_in에도 연결되는지 확인합니다. Reset 입력을 중복으로 만드는 것과 같은 입력을 두 IP에 연결하는 것은 다른 작업입니다.

⑤ 외부 포트 이름과 XDC의 get_ports clk, get_ports btnC가 일치하는지 2교시에서 대조합니다.

보드에서 온 신호BD 외부 이름상대 IP 입력역할
W5 · 100 MHzclkclk_wiz_1/clk_in1기준 Clock
U18 · 가운데 버튼btnCclk_wiz_1/resetClock 회로 초기화 입력
U18 · 같은 버튼btnCrst_clk_wiz_1_100M/ext_reset_in시스템 Reset 요청

용어 구분: 포트 이름을 바꾸는 것은 HDL/BD의 신호 이름 변경이고, XDC의 W5/U18은 물리 핀 번호입니다. 두 항목이 모두 맞아야 합니다.

06. Processor System Reset — 초기화의 이유와 연결

Processor System Reset(프로세서 시스템 리셋, CPU·버스·주변회로 초기화 제어 IP)은 CPU와 버스가 같은 순간에 아무렇게나 실행되지 않도록 Reset 입력을 다룹니다.

포트 또는 설정이번 장 기준쉬운 설명
External Reset Logic LevelActive-High“BTNC를 눌러 High가 되면 Reset을 요청합니다.”
ext_reset_inbtnC로 연결외부 버튼에서 Reset 요청을 받음
dcm_lockedclk_wiz_1/locked로 연결Clock 안정 신호를 받음
slowest_sync_clk100 MHz clk_out1로 연결Reset 제어의 시간 기준이 되는 클록 입력
mb_resetCPU Reset에 연결CPU 동작을 초기 상태로 돌리기 위한 출력
mb_debug_sys_rstMDM V Debug_SYS_Rst 경로디버거의 시스템 Reset 요청 처리
aux_reset_in미사용 시 Active-High 조건에서 0 고정사용하지 않는 보조 Reset이 불필요한 초기화를 일으키지 않도록 함

극성(Polarity, 폴라리티, 신호가 활성화되는 논리값): Active-High는 1일 때 활성, Active-Low는 0일 때 활성입니다. mb_reset과 peripheral_aresetn은 이름과 논리 수준이 다릅니다. Active-Low를 마음대로 한 번 더 뒤집지 않습니다.

질문: “버튼은 기계식이므로 눌렀다 뗄 때 접점이 튀지 않을까요?” → 실제로 바운스가 생길 수 있습니다. Processor System Reset은 Reset 신호를 적절히 처리하지만 일반 목적 버튼 디바운서라고 단정하지 않습니다.

07. 실제 Wire를 따라 다섯 신호 경로 확인

순번실제 연결설명 문장
1 · 기준 Clockclk → clk_wiz_1/clk_in1“보드 W5의 100 MHz가 Clock Wizard로 들어옵니다.”
2 · CPU Clockclk_wiz_1/clk_out1 → microblaze_riscv_0/Clk“정해진 시스템 Clock이 CPU에 공급됩니다.”
3 · 안정 신호clk_wiz_1/locked → rst_clk_wiz_1_100M/dcm_locked“Clock이 안정되었다는 사실을 Reset Controller에 알립니다.”
4 · 외부 ResetbtnC → rst_clk_wiz_1_100M/ext_reset_in“버튼을 누르면 시스템 Reset 요청이 전달됩니다.”
5 · CPU Resetrst_clk_wiz_1_100M/mb_reset → microblaze_riscv_0/Reset“CPU 초기화 출력이 CPU에 도달합니다.”

추가 신호선도 확인

clk_wiz_1/clk_out1 → rst_clk_wiz_1_100M/slowest_sync_clk, btnC → clk_wiz_1/reset, mdm_* Debug Reset, 각 BRAM/버스의 Clock·Reset을 함께 점검합니다.

1교시 완료: 외부 포트와 내부 Clock/Reset 경로가 정합하게 연결된 soc01_mb_bram.bd를 저장합니다. Validate Design·합성·Bitstream 생성은 2교시에 실시합니다.

다음 시간으로 연결: “이제 회로의 선은 연결했습니다. 다음에는 XDC에서 물리 핀을 확인하고 Vivado가 회로를 받아들이는지 Validate하고, 실제 FPGA에 쓸 Bitstream까지 생성하겠습니다.”
