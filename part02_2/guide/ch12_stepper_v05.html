00과제 개요

기존 11장의 서보 모터는 PWM 펄스폭으로 목표 각도를 지시한다. 이번 12장의 스테핑 모터는 코일의 여자 순서, 한 단계의 지속 시간, 실행 스텝 수를 RTL(레지스터 전송 수준)에서 관리한다.

28BYJ-48(5V) 5선 유니폴러 모터와 ULN2003 드라이버 모듈을 사용한다. MicroBlaze V는 AXI4-Lite 레지스터에 명령을 기록하고, 실제 연속 여자 출력은 독립 `stepper_core`가 생성한다.

검증 범위: 신규 코어·AXI IP RTL 시뮬레이션과 C 계산 함수의 호스트 단위 테스트만 완료했다. Vivado 합성/타이밍·Vitis 타깃 BSP/ELF·실제 Basys3 모터 회전은 아직 하지 않았다. 해당 항목을 성공으로 간주하지 않는다.

01하드웨어 계층 구조

Top은 FPGA 핀·wire·인스턴스 연결만 맡는다. 별도의 `p2_12_axi_stepper_v1_0` IP 안에 `stepper_core`를 인스턴스화한다. 07장의 L298N DC 모터 제어 IP는 독립적으로 유지한다.

02실제 부품 및 연결 규칙

5V 모터 전원은 Basys3 FPGA I/O 핀에서 공급하지 않는다. ULN2003의 GND와 Basys3 GND를 공유하며, 실제 ULN2003 보드의 IN1~IN4가 3.3V 입력으로 정상 동작하는지 부품·회로별로 확인한다. 이미 P2-07 L298N에 배정된 JB 포트를 덮어쓰지 않는다. P2-12의 신규 4개 XDC 핀은 Vivado 현행 프로젝트의 배선 충돌 검토 후 확정한다.

ULN2003 LED 모니터 표시를 이용하면 회전 전에도 여자 순서가 올바른지 육안으로 확인할 수 있다. 단, LED 점등은 기계적 회전의 증거가 아니다.

04타이밍 및 제어 계약

`stop_pulse`코일 출력 즉시 LOW·실행 중단최우선

`cfg_step_period`스텝 간 클록 수, 기본 최소 200000START 때만 적용

각도 대신 스텝 수를 직접 지정한다. 기본 클록 100MHz 가정에서 5ms 스텝 주기는 `500000`클록이다. 실제 AXI 클록에 따라 주기 계산값을 바꾼다.

가감속·위치 피드백·기계적 영점 센서는 이번 초기 버전에서 제외한다. 현재 RTL은 일정 주기로 코일을 여자하는 오픈 루프 제어다.

CPU에서 STEP_COUNT → STEP_PERIOD → CONTROL → COMMAND=1 순서로 기록한다. 완료 후 STATUS, STEPS_DONE을 읽는다. 타깃용 Xil_Out32는 AXI BRESP 오류를 그대로 반환하지 않으므로 상태·설정 확인을 함께 수행한다.

06Vivado 및 Vitis 실습

  1. 기존 제2부 완료 프로젝트를 Save As로 `soc_ip_design_12`에 복제. 기존 `soc_hw.xpr` 및 01~10장 폴더는 유지한다.
  2. `rtl/stepper_core.v`와 `rtl/p2_12_axi_stepper_v1_0.v`를 신규 IP로 등록한다. Data Width=32, Address Width=6 이상으로 설정한다.
  3. Block Design에 새 AXI Slave를 추가, 기존 MicroBlaze V AXI Interconnect의 클록·리셋에 연결한다.
  4. Address Editor에서 베이스 주소를 새롭게 지정하고, 기존 01~11장 주소가 바뀌지 않았는지 확인한다.
  5. `stepper_coil_o[3:0]`을 Make External하고 사용자 Top에서 외부 FPGA 핀 4개에 단순 연결한다. `always`/연산/선택 정책을 Top에 추가하지 않는다.
  6. 기존 JB L298N 핀과 충돌하지 않는 핀을 선택해 XDC에 `LVCMOS33` 지정. 전원/드라이버 접속은 별도 검사 후 시행한다.
  7. Validate Design → Output Products → HDL Wrapper → Synthesis → Implementation → Timing → Bitstream → XSA 순서로 확인한다.
  8. Vitis C 코드에 실제 Base Address 및 Clock을 전달하여 STEP_COUNT/STEP_PERIOD/CONTROL/START/STATUS/STOP 순으로 테스트한다.
  9. 모터를 처음 연결할 때는 5ms 저속, 8스텝, 무부하로 확인한 뒤 128스텝 등으로 확대한다. 실제 방향은 드라이버 핀 순서에 따라 반전될 수 있으므로 눈으로 확인한다.

상기 Vivado/Vitis/보드 통합은 구현 안내이며 아직 실행 성공 증거가 없다. 원본 전체 SoC의 자동 증분 통합이나 타이밍이 검증되었다고 기록하지 않는다.

rtl/stepper_core.v — 원본 전체 코드 열기
rtl/stepper_core.v · VERILOG · 소스 원문
`timescale 1ns/1ps
// P2-12 28BYJ-48/ULN2003 Core, FPGA/AXI/보드 독립 RTL.
// 출력 coil_o[0..3]은 ULN2003 IN1..IN4로 순서대로 연결.
// (추가) 고정 2상 Full Step / 1-2상 Half Step.
// (추가) 설정은 START에서 래치하며 동작 중 변경하지 않음.
// (추가) STOP은 조합 출력 게이트 + 클록 동기 상태 중단.
// (주의) 오픈 루프이므로 steps_done은 기계적 축 회전 성공을 보증하지 않음.
module stepper_core #(
    parameter [31:0] MIN_STEP_CYCLES = 32'd200000
)(
    input  wire        clk,
    input  wire        resetn,
    input  wire        start_pulse,
    input  wire        stop_pulse,
    input  wire [31:0] cfg_steps,
    input  wire [31:0] cfg_step_period,
    input  wire        cfg_reverse,
    input  wire        cfg_half_step,
    output wire [3:0]  coil_o,
    output reg         busy,
    output reg         done_pulse,
    output reg         error_pulse,
    output reg [31:0]  steps_done
);
    reg [31:0] target_steps;
    reg [31:0] active_period;
    reg [31:0] ticks_left;
    reg [2:0]  phase;
    reg        active_reverse;
    reg        active_half_step;
    reg [3:0]  coils_q;

    // 코일 비트 순서: [3]=IN4, [2]=IN3, [1]=IN2, [0]=IN1.
    // Half: IN1 -> IN1+IN2 -> IN2 -> IN2+IN3 -> ... -> IN4+IN1.
    function [3:0] coil_pattern;
        input [2:0] idx;
        input       half_step;
        begin
            if (half_step) begin
                case (idx)
                3'd0: coil_pattern = 4'b0001;
                3'd1: coil_pattern = 4'b0011;
                3'd2: coil_pattern = 4'b0010;
                3'd3: coil_pattern = 4'b0110;
                3'd4: coil_pattern = 4'b0100;
                3'd5: coil_pattern = 4'b1100;
                3'd6: coil_pattern = 4'b1000;
                default: coil_pattern = 4'b1001;
                endcase
            end else begin
                case (idx[1:0])
                2'd0: coil_pattern = 4'b0011;
                2'd1: coil_pattern = 4'b0110;
                2'd2: coil_pattern = 4'b1100;
                default: coil_pattern = 4'b1001;
                endcase
            end
        end
    endfunction

    // STOP/RESET이 올라오면 클록을 기다리지 않고 ULN2003 입력을 모두 LOW.
    assign coil_o = (resetn && !stop_pulse) ? coils_q : 4'b0000;

    always @(posedge clk) begin
        if (!resetn) begin
            busy             <= 1'b0;
            done_pulse       <= 1'b0;
            error_pulse      <= 1'b0;
            steps_done       <= 32'd0;
            target_steps     <= 32'd0;
            active_period    <= MIN_STEP_CYCLES;
            ticks_left       <= 32'd0;
            phase            <= 3'd0;
            active_reverse   <= 1'b0;
            active_half_step <= 1'b1;
            coils_q          <= 4'b0000;
        end else begin
            done_pulse  <= 1'b0;
            error_pulse <= 1'b0;
            if (stop_pulse) begin
                busy       <= 1'b0;
                coils_q    <= 4'b0000;
                ticks_left <= 32'd0;
            end else if (start_pulse) begin
                if (busy || cfg_steps == 32'd0 ||
                    cfg_step_period < MIN_STEP_CYCLES) begin
                    error_pulse <= 1'b1;
                end else begin
                    busy             <= 1'b1;
                    steps_done       <= 32'd0;
                    target_steps     <= cfg_steps;
                    active_period    <= cfg_step_period;
                    ticks_left       <= cfg_step_period - 32'd1;
                    active_reverse   <= cfg_reverse;
                    active_half_step <= cfg_half_step;
                    phase            <= 3'd0;
                    coils_q          <= 4'b0000;
                end
            end else if (busy) begin
                if (ticks_left != 32'd0) begin
                    ticks_left <= ticks_left - 32'd1;
                end else begin
                    // 실제 한 스텝 여자하고 카운트 1 증가.
                    coils_q    <= coil_pattern(phase, active_half_step);
                    steps_done <= steps_done + 32'd1;
                    ticks_left <= active_period - 32'd1;
                    if (steps_done + 32'd1 == target_steps) begin
                        busy       <= 1'b0;
                        done_pulse <= 1'b1;
                        // 마지막 여자 패턴은 DONE 한 클록 동안 유지.
                    end else if (active_reverse) begin
                        phase <= active_half_step ?
                                 (phase - 3'd1) :
                                 {1'b0, (phase[1:0] - 2'd1)};
                    end else begin
                        phase <= active_half_step ?
                                 (phase + 3'd1) :
                                 {1'b0, (phase[1:0] + 2'd1)};
                    end
                end
            end else begin
                // 유휴 때 발열 방지를 위해 코일 해제.
                coils_q <= 4'b0000;
            end
        end
    end
endmodule

rtl/p2_12_axi_stepper_v1_0.v · VERILOG · 소스 원문
`timescale 1ns/1ps
// P2-12: 28BYJ-48 Stepper AXI4-Lite IP wrapper (self-contained).
// Original P2-01~10 AXI IPs are not modified.
// Registers: 0x00 STEPS, 0x04 PERIOD_TICKS, 0x08 CONTROL,
//            0x0C CMD, 0x10 STATUS, 0x14 DONE_STEPS,
//            0x18 ID, 0x1C MIN_STEP_TICKS.
// CONTROL bit0=reverse, bit1=half_step. CMD bit0=START, bit1=STOP.
// STATUS bit0=BUSY, bit1=DONE_STICKY, bit2=ERROR_STICKY.
module p2_12_axi_stepper_v1_0 #(
    parameter integer C_S_AXI_DATA_WIDTH = 32,
    parameter integer C_S_AXI_ADDR_WIDTH = 6,
    parameter [31:0] MIN_STEP_CYCLES = 32'd200000,
    parameter [31:0] RESET_STEP_PERIOD = 32'd500000
)(
    input wire S_AXI_ACLK, input wire S_AXI_ARESETN,
    input wire [C_S_AXI_ADDR_WIDTH-1:0] S_AXI_AWADDR,
    input wire [2:0] S_AXI_AWPROT,
    input wire S_AXI_AWVALID, output wire S_AXI_AWREADY,
    input wire [C_S_AXI_DATA_WIDTH-1:0] S_AXI_WDATA,
    input wire [(C_S_AXI_DATA_WIDTH/8)-1:0] S_AXI_WSTRB,
    input wire S_AXI_WVALID, output wire S_AXI_WREADY,
    output reg [1:0] S_AXI_BRESP, output reg S_AXI_BVALID,
    input wire S_AXI_BREADY,
    input wire [C_S_AXI_ADDR_WIDTH-1:0] S_AXI_ARADDR,
    input wire [2:0] S_AXI_ARPROT,
    input wire S_AXI_ARVALID, output wire S_AXI_ARREADY,
    output reg [C_S_AXI_DATA_WIDTH-1:0] S_AXI_RDATA,
    output reg [1:0] S_AXI_RRESP, output reg S_AXI_RVALID,
    input wire S_AXI_RREADY,
    output wire [3:0] stepper_coil_o
);
    localparam [1:0] OKAY = 2'b00, SLVERR = 2'b10;
    localparam [31:0] ID = 32'h000C0001;
    reg [31:0] cfg_steps;
    reg [31:0] cfg_period;
    reg [31:0] cfg_control;
    reg start_strobe, stop_strobe;
    wire busy, done_pulse, error_pulse;
    wire [31:0] steps_done;
    reg done_sticky, error_sticky;
    reg aw_hold, w_hold;
    reg [C_S_AXI_ADDR_WIDTH-1:0] saved_awaddr;
    reg [31:0] saved_wdata;
    reg [3:0] saved_wstrb;
    reg [31:0] merged;
    integer b;

    stepper_core #(.MIN_STEP_CYCLES(MIN_STEP_CYCLES)) u_core (
        .clk(S_AXI_ACLK), .resetn(S_AXI_ARESETN),
        .start_pulse(start_strobe), .stop_pulse(stop_strobe),
        .cfg_steps(cfg_steps), .cfg_step_period(cfg_period),
        .cfg_reverse(cfg_control[0]),.cfg_half_step(cfg_control[1]),
        .coil_o(stepper_coil_o), .busy(busy),
        .done_pulse(done_pulse),.error_pulse(error_pulse),
        .steps_done(steps_done)
    );
    // 각 AW/W 채널 버퍼 한 건 + 응답 한 건만 보관.
    assign S_AXI_AWREADY = S_AXI_ARESETN && !aw_hold && !S_AXI_BVALID;
    assign S_AXI_WREADY  = S_AXI_ARESETN && !w_hold  && !S_AXI_BVALID;
    assign S_AXI_ARREADY = S_AXI_ARESETN && !S_AXI_RVALID;

    always @(posedge S_AXI_ACLK) begin
        if (!S_AXI_ARESETN) begin
            cfg_steps     <= 32'd128;
            cfg_period    <= RESET_STEP_PERIOD;
            cfg_control   <= 32'd2; // default HALF, forward
            aw_hold       <= 1'b0;
            w_hold        <= 1'b0;
            saved_awaddr  <= {C_S_AXI_ADDR_WIDTH{1'b0}};
            saved_wdata   <= 32'd0;
            saved_wstrb   <= 4'd0;
            S_AXI_BVALID  <= 1'b0;
            S_AXI_BRESP   <= OKAY;
            start_strobe  <= 1'b0;
            stop_strobe   <= 1'b0;
            done_sticky   <= 1'b0;
            error_sticky  <= 1'b0;
        end else begin
            start_strobe <= 1'b0;
            stop_strobe  <= 1'b0;
            if (done_pulse) done_sticky <= 1'b1;
            if (error_pulse) error_sticky <= 1'b1;
            if (S_AXI_AWVALID && S_AXI_AWREADY) begin
                saved_awaddr <= S_AXI_AWADDR;
                aw_hold <= 1'b1;
            end
            if (S_AXI_WVALID && S_AXI_WREADY) begin
                saved_wdata <= S_AXI_WDATA;
                saved_wstrb <= S_AXI_WSTRB;
                w_hold <= 1'b1;
            end
            if (S_AXI_BVALID && S_AXI_BREADY)
                S_AXI_BVALID <= 1'b0;
            if (aw_hold && w_hold && !S_AXI_BVALID) begin
                aw_hold <= 1'b0;
                w_hold <= 1'b0;
                S_AXI_BVALID <= 1'b1;
                S_AXI_BRESP <= OKAY;
                case (saved_awaddr)
                6'h00: begin
                    merged=cfg_steps;
                    for (b=0;b<4;b=b+1)
                        if(saved_wstrb[b])
                            merged[8*b +:8]=saved_wdata[8*b +:8];
                    cfg_steps <= merged;
                end
                6'h04: begin
                    merged=cfg_period;
                    for (b=0;b<4;b=b+1)
                        if(saved_wstrb[b])
                            merged[8*b +:8]=saved_wdata[8*b +:8];
                    cfg_period <= merged;
                end
                6'h08: begin
                    merged=cfg_control;
                    for (b=0;b<4;b=b+1)
                        if(saved_wstrb[b])
                            merged[8*b +:8]=saved_wdata[8*b +:8];
                    cfg_control <= (merged & 32'h3);
                end
                6'h0C: begin
                    // 반드시 낮은 바이트 스트로브와 명령 비트가 있어야 함.
                    if (!saved_wstrb[0]) begin
                        S_AXI_BRESP <= SLVERR;
                    end else if (saved_wdata[1] && !saved_wdata[0]) begin
                        stop_strobe <= 1'b1;
                    end else if (saved_wdata[0] && !saved_wdata[1]) begin
                        if (busy || start_strobe || cfg_steps == 0 ||
                            cfg_period < MIN_STEP_CYCLES) begin
                            S_AXI_BRESP <= SLVERR;
                            error_sticky <= 1'b1;
                        end else begin
                            start_strobe <= 1'b1;
                            done_sticky <= 1'b0;
                            error_sticky <= 1'b0;
                        end
                    end else S_AXI_BRESP <= SLVERR;
                end
                default: S_AXI_BRESP <= SLVERR;
                endcase
            end
        end
    end

    always @(posedge S_AXI_ACLK) begin
        if (!S_AXI_ARESETN) begin
            S_AXI_RVALID <= 1'b0;
            S_AXI_RDATA  <= 32'd0;
            S_AXI_RRESP  <= OKAY;
        end else begin
            if (S_AXI_RVALID && S_AXI_RREADY)
                S_AXI_RVALID <= 1'b0;
            if (S_AXI_ARVALID && S_AXI_ARREADY) begin
                S_AXI_RVALID <= 1'b1;
                S_AXI_RRESP <= OKAY;
                case (S_AXI_ARADDR)
                6'h00: S_AXI_RDATA <= cfg_steps;
                6'h04: S_AXI_RDATA <= cfg_period;
                6'h08: S_AXI_RDATA <= cfg_control;
                6'h0C: S_AXI_RDATA <= 32'd0;
                6'h10: S_AXI_RDATA <= {29'd0,error_sticky,done_sticky,busy};
                6'h14: S_AXI_RDATA <= steps_done;
                6'h18: S_AXI_RDATA <= ID;
                6'h1C: S_AXI_RDATA <= MIN_STEP_CYCLES;
                default: begin
                    S_AXI_RDATA <= 32'd0;
                    S_AXI_RRESP <= SLVERR;
                end
                endcase
            end
        end
    end
endmodule

#include "stepper_logic.h"
#include <limits.h>
// 2~100ms: 저속에서 시작. 제조사/부하별 실제 허용 속도는 별도 보드 확인.
// full/half mode의 1스텝 각도와 감속비는 모터마다 달라질 수 있다.
int stepper_make_config(uint32_t clock_hz, uint32_t step_count,
                        uint32_t interval_ms, int reverse,
                        int half_step, stepper_cfg_t *out)
{
    uint64_t ticks;
    if (!out || clock_hz < 1000000u || clock_hz > 200000000u ||
        step_count == 0u || step_count > 100000u ||
        interval_ms < 2u || interval_ms > 100u ||
        (reverse != 0 && reverse != 1) ||
        (half_step != 0 && half_step != 1)) return -1;

    ticks = ((uint64_t)clock_hz * interval_ms) / 1000u;
    if (ticks < 2u || ticks > UINT32_MAX) return -1;
    out->steps = step_count;
    out->period_ticks = (uint32_t)ticks;
    out->control = (uint32_t)reverse | ((uint32_t)half_step << 1);
    return 0;
}

#define REG_STEPS   0x00u

#define REG_CONTROL 0x08u
#define REG_COMMAND 0x0Cu
#define REG_STATUS  0x10u
#define REG_DONE    0x14u
int stepper_axi_start(uintptr_t baseaddr, const stepper_cfg_t *cfg)
{
    if (!cfg || cfg->steps == 0u || cfg->period_ticks < 2u ||
        (cfg->control & ~3u) != 0u) return -1;
    // (주의) 실제 최소 주기(MIN_STEP_TICKS)를 함께 검증해야 한다.
    // Xil_Out32는 AXI BRESP/하드웨어 완료를 자동 반환하지 않음.
    Xil_Out32(baseaddr + REG_STEPS, cfg->steps);
    Xil_Out32(baseaddr + REG_PERIOD, cfg->period_ticks);
    Xil_Out32(baseaddr + REG_CONTROL, cfg->control);
    Xil_Out32(baseaddr + REG_COMMAND, 1u);

}

`timescale 1ns/1ps
module tb_stepper_core;
    reg clk=0; always #5 clk=~clk;
    reg resetn=0,start=0,stop=0;
    reg [31:0] steps=0,period=0;
    reg reverse=0,half=1;
    wire [3:0] coil;
    wire busy,done,error;
    wire [31:0] completed;
    integer i;
    reg [3:0] seq_half [0:7];
    reg [3:0] seq_full [0:3];
    stepper_core #(.MIN_STEP_CYCLES(32'd2)) dut (
        .clk(clk),.resetn(resetn),.start_pulse(start),.stop_pulse(stop),
        .cfg_steps(steps),.cfg_step_period(period),
        .cfg_reverse(reverse),.cfg_half_step(half),
        .coil_o(coil),.busy(busy),.done_pulse(done),
        .error_pulse(error),.steps_done(completed)
    );
    task begin_run;
        input [31:0] n,p;
        input r,h;
        begin
            @(negedge clk);
            steps=n;period=p;reverse=r;half=h;start=1;
            @(negedge clk);start=0;
            if (!busy) $fatal(1,"busy not asserted");
        end
    endtask
    task expect_step;
        input [31:0] n;
        input [3:0] expected;
        begin
            wait(completed == n);
            #1;
            if(coil !== expected)
                $fatal(1,"step %0d expected %b got %b", n,expected,coil);
        end
    endtask
    initial begin
        seq_half[0]=4'b0001;seq_half[1]=4'b0011;
        seq_half[2]=4'b0010;seq_half[3]=4'b0110;
        seq_half[4]=4'b0100;seq_half[5]=4'b1100;
        seq_half[6]=4'b1000;seq_half[7]=4'b1001;
        seq_full[0]=4'b0011;seq_full[1]=4'b0110;
        seq_full[2]=4'b1100;seq_full[3]=4'b1001;
        repeat(3) @(negedge clk); resetn=1;
        if(coil!==0 || busy) $fatal(1,"reset outputs");
        begin_run(8,3,0,1);
        for(i=0;i<8;i=i+1) expect_step(i+1,seq_half[i]);
        // (변경) DONE 직후 한 클록 뒤에 코일을 해제하는 RTL 정책을 기다린다.
        repeat(2) @(negedge clk);
        if(busy || done || coil !== 4'b0000 || completed != 8)
            $fatal(1,"done/idle release");
        $display("HALF_FORWARD PASS");

        begin_run(8,3,1,1);
        expect_step(1,seq_half[0]);
        for(i=1;i<8;i=i+1)
            expect_step(i+1,seq_half[8-i]);
        repeat(2) @(negedge clk);
        if(busy || coil!==0) $fatal(1,"reverse idle");
        $display("HALF_REVERSE PASS");

        begin_run(4,2,0,0);
        for(i=0;i<4;i=i+1) expect_step(i+1,seq_full[i]);
        repeat(2) @(negedge clk);
        if(busy || coil!==0) $fatal(1,"full idle");
        $display("FULL_FORWARD PASS");

        begin_run(4,2,1,0);
        expect_step(1,seq_full[0]);
        for(i=1;i<4;i=i+1) expect_step(i+1,seq_full[4-i]);
        repeat(2) @(negedge clk);
        if(busy || coil!==0) $fatal(1,"full reverse idle");
        $display("FULL_REVERSE PASS");

        // 동작 중 START: 에러 1클록, 진행 상태 유지.
        begin_run(12,3,0,1);
        @(negedge clk);start=1;
        @(negedge clk); start=0;
        if(!error || !busy) $fatal(1,"busy start error");
        @(negedge clk);
        if(error) $fatal(1,"error pulse not cleared");
        // STOP은 클록 전 즉시 코일 OFF.
        #1;stop=1;#1;
        if(coil!==0) $fatal(1,"immediate stop gating");
        @(negedge clk);stop=0;
        if(busy || coil!==0 || done) $fatal(1,"stop failed");
        $display("BUSY_REJECT_STOP PASS");

        // 0 step, period under minimum -> error pulse.
        @(negedge clk);steps=0;period=3;start=1;
        @(negedge clk);start=0;
        if(!error || busy) $fatal(1,"zero steps accepted");
        @(negedge clk);steps=3;period=1;start=1;
        @(negedge clk);start=0;
        if(!error || busy) $fatal(1,"unsafe period accepted");
        $display("INVALID_CONFIG PASS");
        $display("P2_12_RTL_STEPPER_CORE PASS");
        $finish;
    end
    initial begin #200000; $fatal(1,"TIMEOUT"); end
endmodule

// P2-12 AXI IP 회귀: AW/W 독립 도착, WSTRB, 레지스터, 모터 출력,
// BUSY/완료/오류/STOP을 포함한 self-checking testbench.
module tb_p2_12_axi_stepper;
    reg clk=0; always #5 clk=~clk;
    reg resetn=0;
    reg [5:0] awaddr=0,araddr=0;
    reg [2:0] awprot=0,arprot=0;
    reg awvalid=0,wvalid=0,bready=0,arvalid=0,rready=0;

    wire awready,wready,bvalid,arready,rvalid;

    wire [31:0] rdata;
    wire [3:0] coil;
    reg [31:0] read_value;
    p2_12_axi_stepper_v1_0 #(
        .MIN_STEP_CYCLES(32'd2),
        .RESET_STEP_PERIOD(32'd3)
    ) dut (
        .S_AXI_ACLK(clk),.S_AXI_ARESETN(resetn),
        .S_AXI_AWADDR(awaddr),.S_AXI_AWPROT(awprot),
        .S_AXI_AWVALID(awvalid),.S_AXI_AWREADY(awready),
        .S_AXI_WDATA(wdata),.S_AXI_WSTRB(wstrb),
        .S_AXI_WVALID(wvalid),.S_AXI_WREADY(wready),
        .S_AXI_BRESP(bresp),.S_AXI_BVALID(bvalid),
        .S_AXI_BREADY(bready),
        .S_AXI_ARADDR(araddr),.S_AXI_ARPROT(arprot),

        .S_AXI_RDATA(rdata),.S_AXI_RRESP(rresp),
        .S_AXI_RVALID(rvalid),.S_AXI_RREADY(rready),
        .stepper_coil_o(coil)
    );
    task wr;
        input [5:0] addr;
        input [31:0] data;
        input [3:0] strobe;
        input integer w_first;
        input [1:0] expected;
        begin
            @(negedge clk);
            if(w_first) begin
                wdata=data; wstrb=strobe; wvalid=1;
                do @(posedge clk); while(!wready);
                @(negedge clk); wvalid=0;
                repeat(2) @(negedge clk);
                awaddr=addr; awvalid=1;
                do @(posedge clk); while(!awready);
                @(negedge clk); awvalid=0;
            end else begin
                awaddr=addr; awvalid=1;
                do @(posedge clk); while(!awready);
                @(negedge clk); awvalid=0;
                repeat(2) @(negedge clk);
                wdata=data; wstrb=strobe; wvalid=1;
                do @(posedge clk); while(!wready);
                @(negedge clk); wvalid=0;
            end
            wait(bvalid); @(negedge clk);
            if(bresp !== expected)
                $fatal(1,"write 0x%h bresp=%b expected=%b",addr,bresp,expected);
            bready=1;
            @(negedge clk); bready=0;
        end
    endtask
    task rd;
        input [5:0] addr;
        input [1:0] expected;
        begin
            @(negedge clk); araddr=addr; arvalid=1;

            read_value=rdata;
            rready=1;
            @(negedge clk); rready=0;
        end

        rd(6'h08,2'b00);

        wr(6'h0c,32'd1,4'h1,0,2'b00);
        wait(dut.u_core.steps_done >= 1); #1;
        if(coil !== 4'b0001) $fatal(1,"step1 pattern %b",coil);
        wait(dut.done_sticky == 1); #1;
        rd(6'h14,2'b00);
        if(read_value!==4) $fatal(1,"completed 4 steps");
        rd(6'h10,2'b00);
        if(read_value[1]!==1 || read_value[0]!==0) $fatal(1,"status done/busy");

        wr(6'h00,32'd0,4'hf,0,2'b00);
        wr(6'h0c,32'd1,4'h1,1,2'b10);
        rd(6'h10,2'b00);
        if(read_value[2]!==1) $fatal(1,"error sticky");
        wr(6'h04,32'd1,4'hf,0,2'b00);
        wr(6'h00,32'd5,4'hf,0,2'b00);
        wr(6'h0c,32'd1,4'h1,0,2'b10);
        $display("P2_12_AXI_INVALID_CONFIG PASS");

        wr(6'h04,32'd3,4'hf,0,2'b00);
        wr(6'h0c,32'd1,4'h1,0,2'b00);
        wait(dut.u_core.busy); #1;
        // 코일 출력 중 STOP에서 모든 출력을 제어 레벨로 차단.
        wait(dut.u_core.steps_done >= 1); #1;
        wr(6'h0c,32'd2,4'h1,1,2'b00);
