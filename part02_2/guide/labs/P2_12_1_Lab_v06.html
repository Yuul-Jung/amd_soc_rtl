실습 12.1 · Vivado AXI IP 실제 SoC 연결

사용자 IP 패키징 · Block Design · Address Editor · 합성/타이밍 검증

스테핑 모터 후속 실습합성·실물 미검증

1. 개요

기존 제2부 12장의 stepper_core.v와 p2_12_axi_stepper_v1_0.v를 새로운 Vivado 프로젝트에 배치한다. 기존 01~10장 프로젝트와 L298N 모터 제어 IP를 보존하면서 새로운 AXI Slave 인스턴스를 추가한다.

검증 상태: IP 자체의 Icarus Verilog RTL·AXI 시뮬레이션 PASS. 실제 Vivado IP Packager, Block Design 통합, 합성·타이밍, XSA/Vitis/보드는 미실행이다.

기존 경로에 직접 덮어쓰지 않는다. Vivado File → Project → Save As에서 프로젝트별 하위 폴더 soc_ip_design_12를 만든다. 복제 후 Project Summary에서 XPR 경로, Design Sources, IP Repository, BD 파일이 원본을 가리키지 않는지 확인한다.

3. AXI IP 패키징

  1. 새 프로젝트에서 Tools → Create and Package New IP를 연다.
  2. 패키징 전용 경로를 선택하고 두 RTL 소스를 포함한다. 이미 만든 사용자 IP를 패키징하는 경우 Package a Specified Directory 또는 Package Current Project 중 현행 소스 구조에 적합한 방법을 선택한다.
  3. Top을 p2_12_axi_stepper_v1_0로 지정한다. stepper_core가 하위 계층으로 정확하게 연결되는지 확인한다.
  4. IP Packager → Ports and Interfaces에서 S_AXI_ACLK, S_AXI_ARESETN 및 S_AXI_AWADDR~S_AXI_RREADY가 AXI4-Lite Slave Interface로 분류되었는지 확인한다. 자동 추론이 안 되면 포트별 Bus Interface Mapping을 수정한다.
  5. 32-bit Data Width, 최소 6-bit Address Width를 적용하고 stepper_coil_o[3:0]를 일반 4비트 출력으로 유지한다.
  6. Review and Package → Re-Package IP. 기존 IP v1.0과 혼동되지 않도록 사용자 IP의 이름·버전·V-L-N-V를 관리한다.

AMD 공식 안내: UG1118 2024.2 · Create and Package New IP.

4. Block Design 연결

  1. Project Settings → IP → Repository에 신규 IP의 패키징 폴더를 추가하고 Refresh IP Catalog로 표시를 확인한다.
  2. 기존 soc11_integration BD를 복제 프로젝트에서 열고 신규 P2-12 AXI IP를 추가한다.
  3. S_AXI_ACLK와 S_AXI_ARESETN을 기존 AXI 클록과 리셋에 연결한다. 시뮬레이션의 클록 수치를 실물에 무조건 적용하지 않는다.
  4. MicroBlaze V에서 접근하는 AXI SmartConnect/Interconnect에 새 S_AXI를 연결한다.
  5. Address Editor에서 해당 IP에 겹치지 않는 주소 공간을 할당하고, 기존 01~11장 IP 주소도 함께 비교한다.
  6. stepper_coil_o[3:0] 출력을 Make External하고 명칭을 일관되게 유지한다.
  7. Validate Design → Generate Output Products → Create HDL Wrapper. 기존 사용자 Top은 외부 신호 핀과 생성 Wrapper의 해당 포트만 단순 연결한다.

직접 작성한 Top의 이름/포트는 프로젝트의 실제 현행 파일을 우선한다. 이 문서에서는 없는 Wrapper 포트를 추측하여 기존 Top을 덮어쓰지 않는다.

5. 레지스터 및 클록 검증

OffsetRegister확인
0x00STEP_COUNT예: 8, 128
0x04STEP_PERIOD100MHz일 때 5ms는 500000 tick
0x08CONTROL0 Full/FWD, 1 Full/REV, 2 Half/FWD, 3 Half/REV
0x0CCOMMAND1 START, 2 STOP
0x10STATUSbusy/done/error
0x14STEPS_DONE스텝 이벤트 수
0x18ID0x000C0001
0x1CMIN_STEP_TICKS최소 스텝 주기 파라미터

기준 주소를 임의 고정값으로 배포하지 않는다. Address Editor와 XSA 및 실제 BSP를 비교하고 레지스터 접근이 가능한지 확인한다.

6. Vivado 실행 및 Gate

  1. Validate Design 결과의 ERROR/WARNING 상세 확인.
  2. Synthesis 실행 → 신규 모듈의 원치 않는 latch, multicycle 또는 unconstrained 경로가 없는지 확인.
  3. Implementation 실행 → WNS/TNS, 클록, 핀/IOSTANDARD 경고 확인.
  4. Generate Bitstream → Export Hardware(XSA) → Vitis Platform 재생성.
  5. IP ID, STATUS 읽기를 12.3의 Vitis C 스모크 테스트와 연결한다.
