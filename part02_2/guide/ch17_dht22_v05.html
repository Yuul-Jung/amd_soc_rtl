00과제 개요

DHT22(디에이치티22, AM2302)는 온도와 상대습도를 한 번에 전달하는 디지털 센서다. FPGA는 데이터선을 일정 시간 LOW로 유지해 센서에 응답을 요청하고, 센서는 비트별 HIGH 펄스폭을 다르게 만들어 40비트 데이터를 전송한다.

본 실습에서는 40비트 프레임을 정확하게 수신하고, 체크섬 및 오류를 확인한 뒤 온도·습도를 유효 데이터로 등록한다.

현 단계는 Icarus Verilog 시뮬레이션 검증이다. Vivado 합성·타이밍, Vitis 타깃 프로그램, 실물 센서 온습도 측정은 현 단계에서 수행하지 않았다. AXI4-Lite 연결은 후속 확장이며, 본 RTL이 이미 CPU 제어까지 완료한 것은 아니다.

01전체 시스템 계층 구조

Top(탑)은 실제 핀과 모듈 인스턴스를 연결하는 Shell(셸, 외부 연결 계층)만 담당한다. 온습도 값 판정과 시간 제어 기능은 보드에 종속되지 않는 독립 Controller(컨트롤러)에 둔다.

02DHT22와 DS18B20 프로토콜 비교

항목DHT22 — 이번 장DS18B20 — 15장
통신Aosong 고유 단일선 펄스폭Dallas/Maxim 1-Wire
전송 형태센서가 40비트 MSB-first 송신명령·데이터를 LSB-first 송수신
데이터상대습도 + 온도 + 체크섬온도 + Scratchpad + CRC
논리 0/1HIGH 지속 시간으로 구분LOW 시작·해제·샘플 슬롯
처리 주기최소 약 2초온도 해상도별 변환 대기

둘 다 데이터선이 한 개라고 해서 같은 통신 IP를 그대로 공유하면 안 된다. 실제 공통화 가능한 것은 Open-drain I/O 경계와 시간 계수기 구조이며 프로토콜 상태 머신은 각각 달라야 한다.

0340비트 응답과 타이밍

그림은 개념도이며 실제 시간 축의 길이 비율이 아니다. 공식 AM2302 기준으로 센서 응답은 LOW/HIGH 각각 약 80µs, 각 데이터 비트의 LOW는 약 50µs다. HIGH 약 26~28µs는 0, 약 70µs는 1로 해석한다. Aosong 공식 기술자료, 5장.

RTL의 판별 기준은 BIT_THRESHOLD_US=45다. DQ는 2단 플립플롭을 통해 입력 동기화하고 시스템 클록을 계수해 µs(마이크로초) 단위 펄스폭을 측정한다.

04온도·습도 및 체크섬 계산

바이트예제의미
1 RH_H0x02상대습도 상위
2 RH_L0x92상대습도 하위
3 TEMP_H0x00온도 상위·부호
4 TEMP_L0xEA온도 하위
5 SUM0x7E앞 4바이트 합의 하위 8비트

습도는 0x0292의 결과인 658 → 65.8%RH. 온도 0x00EA는 234 → +23.4°C. 체크섬은 (0x02 + 0x92 + 0x00 + 0xEA) & 0xFF의 결과인 0x7E와 비교한다.

음수 온도는 **2의 보수가 아닌 부호와 크기** 형태다. 예를 들어 0x8065는 부호 비트 1과 크기 101을 의미하므로 −10.1°C로 해석한다. 오류 검출 시 기존 유효 출력값을 유지한다.

2초 쿨다운은 첫 정상/오류 결과 이후 적용한다. 전원 투입 직후 최소 2초 안정화는 현재 외부 제어 측에서 보장해야 하며, 이 기능을 RTL 내부에 이미 포함한 것으로 보지 않는다.

06하드웨어 연결 및 전기적 안전

일반 DHT22 센서 모듈은 VCC, DATA, GND를 이용한다. 사용 모듈의 전원·풀업 배치를 확인하여 DQ는 약 4.7kΩ 풀업을 Basys3 호환 3.3V에 연결한다. 모듈에 풀업이 이미 있는 경우 중복 설치 전 회로를 확인한다.

Basys3 FPGA I/O에 5V DATA 또는 5V 풀업 전압을 직접 인가하지 않는다. 제조사 권장 전압과 실제 구매 모듈의 구성은 다를 수 있으므로 실물 연결 전 확인한다. DQ의 XDC 핀은 기존 01~16장과 중복되지 않는 포트로 별도 확정한다.

07전체 RTL·테스트벤치

아래 RTL 코드는 별도의 FPGA 보드 핀 명칭과 독립적으로 동작하도록 작성됐다. 테스트벤치는 가짜 DHT22가 직접 40비트 펄스열을 발생시키는 self-checking 방식이다. Vivado용 IOBUF는 Xilinx Primitive이므로 Icarus 휴대용 시뮬레이션에는 포함하지 않는다.

rtl/dht22_controller.v — 전체 코드 펼치기
rtl/dht22_controller.v · VERILOG · 소스 원문
`timescale 1ns/1ps
// P2-17 DHT22/AM2302 separate one-wire pulse-width receiver.
// Unlike DS18B20 Dallas 1-Wire, this is Aosong's 40-bit protocol.
// Output units: humidity_tenths = 0.1 %RH, temperature_tenths = 0.1 C.
// DHT22 temperature uses sign-magnitude (NOT two's complement).
// No clock generated: samples synchronized dq_in using system clk.
// Timing parameters are microseconds, CLK_HZ must divide by 1_000_000.
// Only pull LOW or release: dq_drive_low=1 => LOW, 0=>external 3.3V pullup.
// No AXI, XDC or FPGA board logic in this reusable controller.
module dht22_controller #(
    parameter integer CLK_HZ=100000000,
    parameter integer START_LOW_US=1200,
    parameter integer RESPONSE_TIMEOUT_US=200,
    parameter integer PULSE_TIMEOUT_US=120,
    parameter integer BIT_THRESHOLD_US=45,
    parameter integer MIN_INTERVAL_US=2000000
)(
    input wire clk,input wire resetn,
    input wire start_pulse,
    input wire dq_in,
    output wire dq_drive_low,
    output reg busy,output reg done_pulse,output reg error_pulse,
    output reg [2:0] error_code, // 1 timeout, 2 checksum, 3 pulse, 4 bad range
    output reg [15:0] humidity_tenths,
    output reg signed [15:0] temperature_tenths,
    output wire sample_ready
);
    localparam integer TICKS_PER_US=CLK_HZ/1000000;
    localparam [3:0] IDLE=0, START_LOW=1, WAIT_RESP_LOW=2,
        RESP_LOW=3, RESP_HIGH=4, BIT_LOW=5, BIT_HIGH=6,
        VALIDATE=7, SUCCESS=8, FAIL=9;
    reg [3:0] state;
    reg [31:0] us_div, elapsed, cooldown;
    reg [5:0] bit_count;
    reg [39:0] shift_data;
    reg [2:0] fail_reason;
    reg dq_meta,dq_sync,dq_prev;
    wire tick_us=(us_div==TICKS_PER_US-1);
    wire rise=dq_sync && !dq_prev;
    wire fall=!dq_sync && dq_prev;
    wire [7:0] chk_sum=shift_data[39:32]+shift_data[31:24]+
                        shift_data[23:16]+shift_data[15:8];
    wire [15:0] rh_raw=shift_data[39:24];
    wire [15:0] temp_mag={1'b0,shift_data[22:8]};
    assign sample_ready=(state==IDLE && cooldown==0);
    assign dq_drive_low=(state==START_LOW && resetn);
    always @(posedge clk) begin
        if(!resetn) begin
            state<=IDLE;us_div<=0;elapsed<=0;cooldown<=0;
            bit_count<=0;shift_data<=0;fail_reason<=0;
            dq_meta<=1;dq_sync<=1;dq_prev<=1;
            busy<=0;done_pulse<=0;error_pulse<=0;
            error_code<=0;humidity_tenths<=0;temperature_tenths<=0;
        end else begin
            // Input synchronization: metastability risk reduced to 2 FF.
            dq_meta<=dq_in;dq_sync<=dq_meta;dq_prev<=dq_sync;
            done_pulse<=0;error_pulse<=0;
            if(tick_us) us_div<=0;
            else us_div<=us_div+1;
            if(tick_us && cooldown!=0) cooldown<=cooldown-1;
            if(tick_us && state!=IDLE && state!=SUCCESS && state!=FAIL)
                elapsed<=elapsed+1;
            case(state)
            IDLE: if(start_pulse && cooldown==0) begin
                busy<=1;error_code<=0;shift_data<=0;bit_count<=0;
                elapsed<=0;state<=START_LOW;
            end
            START_LOW: if(tick_us && elapsed>=START_LOW_US-1)begin
                elapsed<=0;state<=WAIT_RESP_LOW;
            end
            WAIT_RESP_LOW: begin
                if(fall)begin elapsed<=0;state<=RESP_LOW;end
                else if(tick_us && elapsed>=RESPONSE_TIMEOUT_US)begin
                    fail_reason<=1;state<=FAIL;
                end
            end
            RESP_LOW: begin
                if(rise)begin
                    if(elapsed<60 || elapsed>100)begin
                        fail_reason<=3;state<=FAIL;
                    end else begin elapsed<=0;state<=RESP_HIGH;end
                end else if(tick_us && elapsed>=PULSE_TIMEOUT_US)begin
                    fail_reason<=1;state<=FAIL;
                end
            end
            RESP_HIGH: begin
                if(fall)begin
                    if(elapsed<60 || elapsed>100)begin
                        fail_reason<=3;state<=FAIL;
                    end else begin elapsed<=0;state<=BIT_LOW;end
                end else if(tick_us && elapsed>=PULSE_TIMEOUT_US)begin
                    fail_reason<=1;state<=FAIL;
                end
            end
            BIT_LOW: begin
                if(rise)begin
                    if(elapsed<35 || elapsed>75)begin
                        fail_reason<=3;state<=FAIL;
                    end else begin elapsed<=0;state<=BIT_HIGH;end
                end else if(tick_us && elapsed>=PULSE_TIMEOUT_US)begin
                    fail_reason<=1;state<=FAIL;
                end
            end
            BIT_HIGH: begin
                if(fall)begin
                    if(elapsed<15 || elapsed>95)begin
                        fail_reason<=3;state<=FAIL;
                    end else begin
                        // (변경) 40 bits arrive MSB first; last bit is LSB.
                        shift_data<={shift_data[38:0],
                                     elapsed>=BIT_THRESHOLD_US};
                        elapsed<=0;
                        if(bit_count==39)state<=VALIDATE;
                        else begin bit_count<=bit_count+1;state<=BIT_LOW;end
                    end
                end else if(tick_us && elapsed>=PULSE_TIMEOUT_US)begin
                    fail_reason<=1;state<=FAIL;
                end
            end
            VALIDATE: begin
                if(chk_sum!=shift_data[7:0])begin
                    fail_reason<=2;state<=FAIL;
                end else if(rh_raw>1000 || temp_mag>800)begin
                    fail_reason<=4;state<=FAIL;
                end else begin
                    // Publish only the validated measurement pair.
                    humidity_tenths<=rh_raw;
                    temperature_tenths<=shift_data[23] ?
                        -$signed(temp_mag) : $signed(temp_mag);
                    state<=SUCCESS;
                end
            end
            SUCCESS: begin
                busy<=0;done_pulse<=1;cooldown<=MIN_INTERVAL_US;
                state<=IDLE;
            end
            FAIL: begin
                busy<=0;error_pulse<=1;error_code<=fail_reason;
                cooldown<=MIN_INTERVAL_US;state<=IDLE;
            end
            default:begin fail_reason<=1;state<=FAIL;end
            endcase
        end
    end
endmodule

// Xilinx Vivado-only physical open-drain pin wrapper (NOT in portable TB).
// External pullup to SAFE 3.3V; never pull DQ high with FPGA output.
module dht22_open_drain_io(
    input wire dq_drive_low,
    inout wire dht22_dq,
    output wire dq_in
);
    IOBUF u_dht22_dq(.I(1'b0),.T(~dq_drive_low),.O(dq_in),.IO(dht22_dq));
endmodule
tests/tb_dht22_controller.v — 전체 코드 펼치기
tests/tb_dht22_controller.v · VERILOG · 소스 원문
`timescale 1ns/1ps
// P2-17 self-checking fake DHT22 pulse-width source.
// Testbench sim clock = 1MHz (one clk per 1us); DUT RTL default 100MHz.
// Positive humidity+temperature, sign magnitude negative temperature,
// checksum corruption, silent sensor, too-short data pulse, cooldown.
module tb_dht22_controller;
    reg clk=0;always #500 clk=~clk; // 1 MHz
    reg resetn=0,start=0,slave_low=0;
    reg respond=1, bad_pulse=0;
    reg [39:0] frame=40'h029200EA7E;
    wire drive_low,busy,done,error,ready;
    wire [2:0] error_code;
    wire [15:0] humidity;
    wire signed [15:0] temperature;
    wire dq_in=!(drive_low||slave_low);
    integer k,frame_count=0;
    dht22_controller #(
        .CLK_HZ(1000000),.START_LOW_US(1200),
        .RESPONSE_TIMEOUT_US(200),.MIN_INTERVAL_US(150)
    ) dut (
        .clk(clk),.resetn(resetn),.start_pulse(start),
        .dq_in(dq_in),.dq_drive_low(drive_low),
        .busy(busy),.done_pulse(done),.error_pulse(error),
        .error_code(error_code),.humidity_tenths(humidity),
        .temperature_tenths(temperature),.sample_ready(ready)
    );
    // Sensor responds only after FPGA releases its initial START LOW.
    always @(negedge drive_low) if(respond && resetn) begin
        frame_count=frame_count+1;
        #30000;            // host release high for ~30us
        slave_low=1;#80000; // sensor 80us response LOW
        slave_low=0;#80000;// sensor 80us response HIGH
        for(k=39;k>=0;k=k-1)begin
            slave_low=1;#50000; // bit start 50us LOW
            slave_low=0;
            if(bad_pulse && k==12) #9000;
            else if(frame[k]) #70000;
            else #28000;
        end
        slave_low=1;#50000; // sensor's final LOW then release
        slave_low=0;
    end
    task issue;
        begin
            wait(ready);
            @(negedge clk);start=1;
            @(negedge clk);start=0;
            if(!busy) $fatal(1,"busy not set");
        end
    endtask
    initial begin
        repeat(4) @(negedge clk);resetn=1;
        issue();
        wait(done);#1;
        if(busy || error || humidity!=658 || temperature!=234)
            $fatal(1,"positive decode RH=%0d TEMP=%0d",humidity,temperature);
        if(!error_code && frame_count==1)
            $display("P2_17_DHT22_POSITIVE_40BIT_PASS");
        else $fatal(1,"unexpected error");
        // Cooldown rejects a command while sample_ready=0.
        @(negedge clk);start=1;
        @(negedge clk);start=0;
        if(busy || frame_count!=1) $fatal(1,"cooldown accepted command");
        $display("P2_17_DHT22_COOLDOWN_PASS");

        frame=40'h01F48065DA; // 50.0% RH, -10.1 deg C
        issue();
        wait(done);#1;
        if(humidity!=500 || temperature!=-101)
            $fatal(1,"negative sign-magnitude temp %0d RH %0d",
                   temperature,humidity);
        $display("P2_17_DHT22_NEGATIVE_TEMP_PASS");

        frame=40'h029200EA00; // intentionally invalid checksum
        issue();wait(error);#1;
        if(error_code!=2 || humidity!=500 || temperature!=-101)
            $fatal(1,"checksum not rejected/previous data destroyed");
        $display("P2_17_DHT22_CHECKSUM_REJECT_PASS");

        respond=0;issue();wait(error);#1;
        if(error_code!=1 || busy || humidity!=500)
            $fatal(1,"missing response not handled");
        $display("P2_17_DHT22_NO_RESPONSE_PASS");

        respond=1;bad_pulse=1;frame=40'h029200EA7E;
        issue();wait(error);#1;
        if(error_code!=3 || humidity!=500)
            $fatal(1,"invalid high pulse was accepted");
        $display("P2_17_DHT22_PULSE_WIDTH_REJECT_PASS");

        $display("P2_17_DHT22_CONTROLLER_RTL PASS");
        $finish;
    end
    initial begin #1000000000; $fatal(1,"TB TIMEOUT");end
endmodule
